We can demonstrate that solving the problem in the feature space is not easy.

Given a non linear function map $$\Phi:\mathbb{R}^{m_{o}}  \to \mathbb{R}^{m_{1}}$$
$$x \mapsto \Phi(x)$$
The problem is formulated as before but the TR is now $$T=\{\Phi(x_{i}, d_{i})\}\quad \forall i = 1 \dots N$$ and the hyperplane is now $$w^T \Phi(x) + b = 0$$
Incorporating the bias in $w$:
$$\Phi(x) = (\underbrace{1}_{\phi_{0}(x)}, \phi_{1}(x), \dots, \phi_{m_{1}}(x))^T$$ $$w_{0} = b$$
So the decision surface equation is now $$w^T \Phi(x) = 0$$
- the dimension of the enlarged space can increase a lot
- the complexity depends from the margin
	- not the space dimension (directly)

$w$ is a *linear combination* of the feature vectors $$w = \sum_{i=1}^N \alpha_{i} d_{i} \Phi(x_{i})$$ so the hyperplane equation is $$\sum_{i=1}^N \alpha_{i} d_{i} \;\underbrace{\Phi^T(x_{i}) \Phi(x)}_{\text{dot product}} = 0$$the dot product is now *in the feature space*.

But evaluating $\Phi(x)$ is **intractable**.
