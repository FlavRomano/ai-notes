The KKT conditions for soft margin includes
- Complementary slackness for both constraints $$\alpha_{i}(d_{i}(w^Tx_{i} + b) + \xi_{i} - 1)=0\quad \forall i = 1 \dots N$$
- $\mu_{i}$ new Lagrange multipliers enforcing non-negativity of the slack variables $\xi_{i}$ $$\mu_{i} \xi_{i} = 0 \quad\forall i = 1 \dots N$$
- bounded multipliers $$0 < \alpha_{i} < C \implies \xi_{i} = 0 \;\text{(on the margin)}$$ $$\alpha_{i}= C \implies \xi_{i} \geq 0 \; \text{(inside the margin)}$$
