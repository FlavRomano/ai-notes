The hold out cross validation starts with
![[Pasted image 20250928222324.png]]
- dividing the data set in 3 disjoint set
	1. TR
		- is used to train the model
		- and make the fitting
	2. VL (Validation Set)
		- select the best model
		- hyper-parameters tuning
	3. TS (Test Set)
		- used only for model assessment
		- estimates accuracy of the model on NEW unseen data
		- it's not made to make model selection.

![[Pasted image 20250928222352.png]]
> If we have low accuracy on model assessment we need to discard all the work we did and start again.


---

If we achieved 
- high accuracy on Validation Set  
- bad accuracy on Test Set
- then it means that A large gap the model has poor generalization.
	- the hypothesis class is **too complex relative to the dataset size**.
	- VC-dim high
