Categorical categories (e.g Gender, Music Genre) can introduce some issues inside a ML model:
- ordinality
	- many categories does not have an order per-se
	- gender M encoded 0 should not "come first" to gender F encoded to 1
	- model can interpret this as a ranking 
		- lead to biased predictions.
- Compatibility with Algorithms
	- many ml algorithms are based on linear regression and gradient descent
		- use numbers
