In ML we are interested in making inferences of unobserved random variables with some prior knowledge (other random variables observed in the past).

Given 
- some prior knowledge $p(x)$ about an unobserved random variable $x$
- some relationship $p(y\mid x)$ between $x$ and a second random variable $y$

Observing $y$
- we can use **Bayes' theorem** to draw some conclusions about $x$ 
- given the observed values of $y$ $$p(x \mid y) = \frac{p(y\mid x)p(x)}{p(y)}$$

> this formula is a direct consequence of the product rule, since $$p(x,y) = p(x\mid y) p(y),\quad p(x,y) = p(y\mid x) p(x)$$
> so that $$p(x\mid y) p(y) = p(y\mid x) p(x) \iff p(x\mid y) = \frac{p(y\mid x) p(x)}{p(y) }$$
