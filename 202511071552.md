Each unit computes the [[202511061726|inner product kernel]] between the input vector and one support vector.

Then each unit output + bias is used to calculate the net.

- The **input layer**: components of $x$.
    
- The **hidden layer**: each neuron computes a **kernel** $$K(\mathbf{x}, \mathbf{x}_i)$$
    
- The **output neuron**: performs a **weighted linear sum** of kernel outputs.
    

So, the SVM behaves like a **one-hidden-layer neural network**, where the “hidden neurons” are **fixed kernel functions** centered at support vectors.
