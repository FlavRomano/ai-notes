When the target space $\mathcal{T}$ is discrete
- we can specify the probability that a random variable $X$ takes a particular value $x\in T$ $$P(X=x)=\text{probability mass function}$$
- we can imagine the probability distribution of multiple random variables as **filling out an (multidimensional) array of numbers**
	- see joint probability
