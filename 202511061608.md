Given the TR set $$T=\{(x_{i}, d_{i})\}\quad\forall i = 1 \dots N$$
we want to
- find $w$ and $b$
- which minimize the objective function $$\psi(w,\xi) = \frac{1}{2} w^T w + C \sum_{i=1}^N \xi_{i}$$

under the following constraints:
- admitting misclassification w.r.t the slack variables $$d_{i}(w^T x_{i} + b)\geq 1\quad \forall i = 1 \dots N$$
- considering only positive slack variables $$\xi_{i} \geq 0 \quad \forall i = 1 \dots N$$
---

The objective function has one hyper-parameter used for regularization.

$C$ is, in fact, in charge to regulate how softer the margin is.

- Low $C$
	- many TR errors allowed
	- possible underfitting
- High $C$
	- **no** TR errors allowed
	- **smaller** margin
	- possible overfitting
	- that's the hard margin case of SVM
