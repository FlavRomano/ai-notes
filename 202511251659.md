In deep learning each layer
- learns a representation of data
- at a different abstraction level

e.g:
- low layers
	- simplest features
	- colors, edges
- intermediate layers
	- combination of simple features
	- shapes, part of objects
- high layers
	- complex and abstract concepts
	- categories, entire objects

In deep learning 
- features that before 
	- were engineered by human
		- extracted by knowing the data
		- e.g texture from images
- now are learnt automatically
	- the network discovers a representations hierarchy
	- thank to the many layers

The network  
- reuse knowledge learnt at lower layers
- generalize better even with few example
- capture latent structure in the data
