The graph lives in a $k+1$ space with $k$ dimension of input.

It's important to picture the function in the original space $$L(f,v)=\{x\in \mathbb{R} : f(x) = v\} \subset \mathbb{R}$$
- the level set takes two parameters
	- the function $f$
	- a value $v \in \mathbb{R}$
- tells me for which points $x$ the function $f$ is equal to $v$

---

The **root of $f$** is equal to the level set of zero $$L(f,0)$$
