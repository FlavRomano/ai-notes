Classification is
- a type of **supervised learning**
- the model is trained with labeled example $$<in,out> = <x, d>$$ where $d$ are a categorical label, simply the class of $x$
	- the function $f$ return the **correct class for $x$**
- the key is to find a linear separator
	- can be a line, hyperplane
	- or very complex when we have non-linear boundaries
