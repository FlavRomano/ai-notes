- input layer annotated with $i$
	- just store the input
	- don't compute any net
	- output $o_{i}$ (is equal to $x_{i}$)
- hidden layer annotated with $j$
	- output $o_{j}$
	- compute its net $net_{j}(x_{i})$
	- compute the intermediate activation function $f_{j}$
- output layer annotated with $k$
	- output $o_k$
	- compute its net $net_{k}(f_{j}(net_{j}(x_{i})))$
	- compute the output activation function $f_{k}$
		- if it's linear => regression tasks
		- if it's sigmoidal => classification tasks
	- with multi-regression or multi-class classifier we have N output units
