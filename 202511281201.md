With curse of dimensionality we now that
- increasing input dimensionality
- implies more sparse example
	- we need more training examples to generalize better
	- because we have a lot of distanciated regions
		- and we need some examples for each region

> To distinguish O(k) regions in input space, these methods require O(k) examples

If we make a too strong assumption, based on a task
- e.g hand-engineered features
- we lack on generalization

The [[general deep models assumption]]
- if the function (that generated the data) has compositional structure
- then with less example we can distinguish **exponential number** of region
	- because deep model reuse previously learnt features
	- distinguish (generalize) in a global way
		- not a "local-way" like k-nn do
	- combines simple features to represent complex patterns

**MORE BENEFITS** with **LESS EXAMPLE**

---

- kNN must “see” an eye in every possible position
	- **impossible**
- A CNN learns the concept of “eye” 
	- and reuses it everywhere
	- *incredible*
