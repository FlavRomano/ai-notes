The **0/1 loss function** is defined as:

$$L(h_w(x_p), d_p) =
\begin{cases} 
0 & \text{if } h_w(x_p) = d_p \\
1 & \text{otherwise}
\end{cases}$$
- **0**
	- No error 
	- correct classification
- **1**
	- Error 
	- misclassification

The inner loss 
- simply counts whether a prediction is correct or incorrect.

---

So over a dataset of $l$ samples the empirical loss is $$E(w) = \frac{1}{l} \sum_{p=1}^l L(h_{w}(x_{p}), d_{p}) $$ is just the **classification error rate**.

---
There are some issue with the 0/1 loss
- **Non-differentiable:**
	- The function is discontinuous (sharp jump between 0 and 1)
	- This makes it unsuitable for **gradient-based optimization methods**, 
		- which require smooth, differentiable loss functions.

0/1 loss remains useful as an **evaluation metric** (classification error rate).
