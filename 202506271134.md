A **random variable** is a function $X:\Omega\to \mathcal{T}$ that takes an outcome $\omega \in \Omega$ and returns a particular quantity of interest $x\in \mathcal{T}$ of target space.

e.g in case of tossing two coins and counting the number of heads
- a random variable $X$ maps to 3 possible outcomes $$X(hh) = 2, \quad X(ht) = 1, \quad X(th)= 1$$ and $X(tt) = 0$
- in this case $\mathcal{T} = \{ 0,1,2 \}$ 

For any subset $S \subseteq \mathcal{T}$ we associate the probability $P_{X}(S) \in [ 0,1 ]$ to a particular event occurring corresponding to the random variable $X$.

> We say that a random variable $X$ is distributed **according to a particular probability distribution $P_{X}$**

We call $P_{X}$ the **distribution** of random variable $X$
