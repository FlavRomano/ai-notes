The standard linear regression assumes that the relationship between the input $x$ and output $y$ is linear
$$y = w_{0} + w_{1}x_{1} + \dots + w_{n}x_{n}$$so $y$ can be written as linear combination of input $x$ and weights $w$.

Most of the time real-world scenarios require **nonlinear** relationship between $x$ and $y$. Because the linear model is too simple
- produce underfitting (high bias)
- fail to model curved relationships
- generalize poorly.

---

**Linear Basis Expansion** solves this by
- transforming the **input feature**
- into new features
- through a **basis functions** $\phi_{i}(x)$
	- augment the input vector with additional variables
	- nonlinear transformations
	- while keeping the model **linear in parameters** (and of course in $\phi$)
		- we can use the same learning algorithm as before

$$h_{w}(x) = \sum_{k=0}^K w_{k} \phi_{k}(x),\quad K>n\text{ (typically)}$$
e.g: 
- polynomial representation of $x$$$\phi(x)=x_{j}^2$$
- non-linear transformation of single inputs $$\phi(x) = \log(x_{j}), \phi(x)=\sqrt{ x_{j} }$$

But there are many cons:
- we are adding complexity to the model
	- so we easily risk overfitting
- [[202510051219|curse of dimensionality]]
- phi are **fixed** before observing training data
