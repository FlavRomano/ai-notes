Given 
- $x$ input space in $\mathbb{R}$
- $y$ output space in $\mathbb{R}$
- $f:\mathbb{R}\to \mathbb{R}$ a function
	- $f(x) = y = \text{output with input } x$
	- for each $x$ we got a point in the space $y$

We define **grap of $f$** the following $$gr(f) = \{(f(x), x) : x \in \mathbb{R}\} \subset \mathbb{R}^2$$
by sliding the $x$ on the $y$ we got the graph.
- the graph of $f$ lives in a $k+1$ dimension 
	- where $k$ is the dimension of the input of $f$
	- so if $x$ is a point, $f$ is a line
