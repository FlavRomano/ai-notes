Given 
- $X$ input space of size $N$ $$\lvert X \rvert = N = \#\text{instances in the input space}$$
- $H$ hypothesis space

Considering the problem of binary classification, there are $2^N$ possible **dichotomies** $$\#\text{dichotomies} = \# \text{partitions of the } N \text{ points by }-1/+1 = 2^N$$
> A **dichotomy** is represented in $\mathcal{H}$ $$\text{ dichotomy represented in }\mathcal{H} \iff \exists h\in H \text{ s.t } h \text{ realizes the dichotomy}$$if there exists an hypothesis $h$ that realizes the dichotomy. 

So $\mathcal{H}$ shatters $X$ if and only if 
- $\mathcal{H}$ can represent all the possible dichotomies on $X$
- so there are 0 errors
	- the points in $X$ can be separated by an $h$ in **all possible ways**
	- for every dichotomy of $X$
		- there exists a consistent hypothesis $h \in \mathcal{H}$

If arbitrarily large (but finite) sets of $X$ can be shattered by $\mathcal{H}$, then $VC(\mathcal{H})$ is infinite.
