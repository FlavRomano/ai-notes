Model complexity refers to 
>the **capacity or flexibility** of a machine learning model to fit a wide variety of functions or patterns.

- A **simple model** 
	- has limited flexibility 
	- e.g. linear regression can only represent straight-line relationships.
    
- A **complex model** 
	- has greater flexibility 
	- e.g., deep neural networks can approximate highly nonlinear functions

---

There are different perspectives for defining model complexity

- **Number of parameters**
	- more weights and biases usually
	- more complex.
    
- **Hypothesis space size**
	- Larger set of functions the model can represent.
    
- **VC dimension**
    
- **Effective complexity** 
	- How well the model adapts to the training data 
	- can it capture noise vs. signal?

---

Model complexity impacts directly learning
- **Underfitting** 
	- the model is **too simple**
	- it cannot capture important patterns
		- high bias.
    
- **Overfitting**:  
	- If the model is **too complex**
	- it memorizes noise in the training set 
		- high variance.
