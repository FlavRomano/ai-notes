We want to find an hyperplane $w^T x$, we first need to define a decision boundary $$x^Tw = w^{T}x = 0$$
- is a separating hyperplane in the input space $\mathbb{R}^n$

in $\mathbb{R}^2$ is $$w_{0} + w_{1}x_{1} + w_{2}x_{2} = 0$$ so the linear model we seen with linear regression.
