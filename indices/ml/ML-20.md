1. **Introduction to Sequential Data**
    *   Transition from flat vectors to structured data (sequences).
	    * output of the model depends on the history of the inputs (time related)
    *   Difference between Feedforward (static) and Recurrent (dynamic/memory) architectures.
    *   Domains and applications: Time series, language processing, robotics.

2.  **Sequence Transduction and Memory Approaches**
    *   Transduction types: Sequence classification, next-step prediction, and generation.
	    * [[transduction]]
    *   **Approach 1: Finite Memory (Time-Delay NN)**
        *   Using sliding windows/buffers.
	        * [[202602271135|TDNN]]
        *   Limitations: Fixed window size.
    *   **Approach 2: Adaptive Memory (RNN)**
        *   Internal state context and feedback loops.
	        * [[202602271145|recurrent unit]]
	        * [[202602271210|transition state]]

3.  **The Recurrent Neural Network (RNN) Model**
    *   **The Elman Network:** Architecture of a Simple RNN.
	    * [[202602271218|elman network]]
    *   **Formalization:** State transition functions ($\tau$) and output functions.
    *   **Key Assumptions:**
        *   *Causality:* Output depends only on past inputs.
	        * [[202602271230|causality]]
        *   *Stationarity:* Weight sharing across time steps.
	        * [[202602271233|stationarity]]
        *   *Adaptivity:* Transition functions are learnt from data.

4.  **Training RNNs**
    *   **Unfolding:** treating the RNN as a deep network over time steps.
	    * [[202602271238|rnn unfolding]]
    *   **Algorithms:** Back-Propagation Through Time (BPTT) and Real-Time Recurrent Learning (RTRL).
	    * Once the network is unfolded, we can calculate the loss at the output and work backward to update the weights
	    * [[202602271411|BPTT]]
    *   **Challenges:** The vanishing gradient problem in long sequences.

5.  **Advanced Architectures**
    *   **Gated Models:** LSTM and GRU to handle long-term dependencies.
    *   **Transformers:** Parallel processing via Attention mechanisms (foundation of GPT).
	    * [[202602271421|transformers]]

6.  **Reservoir Computing (RC) and Echo State Networks (ESN)**
    *   **Concept:** Using a fixed, random recurrent "reservoir" with a trainable linear readout.
	    * [[202602271433|echo state network]]
	    * [[202602271442|echo state property]]
    *   **Advantages:** High training efficiency (linear regression) and Markovian state organization.
	    * [[202602271447|markovian projection]]
    *   **DeepESN:** Hierarchical temporal feature extraction.

7.  **Extension to Structured Domains**
    *   **Recursive Neural Networks:** Generalizing RNNs from sequences to Tree structures.
    *   Weight sharing across tree nodes.
