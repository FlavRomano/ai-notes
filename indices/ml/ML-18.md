1.  **Random Weights Neural Networks (RWNN)**
    *   **Core Concept:** A network with a fixed, randomly initialized hidden layer and a trainable linear output layer.
	    - [[202602242123|random weights neural networks]]
    *   **Architecture:** Input $\rightarrow$ Untrained Non-linear Projection $\rightarrow$ Trained Linear Readout.
	    * [[202602242126|randomized nn architecture]]

2.  **Theoretical Foundation**
    *   **Basis Expansion:** Projecting inputs into a high-dimensional feature space.
	    * [[202602242132|untrained hidden layer]]
    *   **Cover’s Theorem (1965):** High-dimensional non-linear projections increase the probability of linear separability.
	    * [[202602242139|Cover's Theorem]]

3.  **Learning Algorithm**
    *   **Construction:** Fill hidden weights ($W$) with random noise (e.g., Gaussian).
    *   **Training:** Solve only for output weights ($W^{out}$) using a direct closed-form solution (Least Squares/Pseudoinverse or Ridge Regression).
	    * [[202602242146|readout]]

4.  **Key Literature Models**
    *   Random Vector Functional-Link (RVFL).
    *   Extreme Learning Machine (ELM).
    *   RBF with random centers.

5.  **Analysis & Applications**
    *   **Pros:** Extreme computational efficiency, simplicity.
    *   **Cons:** Debate regarding "random" vs. "learned" features.
    *   **Use Cases:** Big Data, Edge Computing/IoT (Tiny ML), and initialization for Deep Learning/RNNs.
