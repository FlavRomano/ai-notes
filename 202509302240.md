The Linear Threshold Unit 
- is the indicator function
	- defines the **decision regions** in input space
- used by a linear classifier

To determine $h(x)$ it takes the weighed sum of inputs and bias $$w_{0} + \sum_{i=0}^n w_{i}x_{i}$$ and use 
- the sign $$h(x)=sign(w^T x + w_{0})$$ for output -1,+1
- a threshold $$h(x) =
\begin{cases}
1 & \text{if } w x + w_{0} \geq 0 \\
0 & \text{otherwise}
\end{cases}$$
for output range 0/1.

The point 
- at which the LTU switches its output
- defines the **decision boundary** (separating hyperplane) $$w^Tx + w_{0}  = 0$$

In LTU the threshold term $w_{0}$ is fundamental
- in fact rule the change of decision $$\begin{align}
h(x) &= w^Tx + w_{0} \ge 0  \\
&= w^Tx \ge -w_{0}
\end{align}$$
- $-w_{0}$ is the necessary value 
	- the weighted inputs must meet
	- to activate the positive output of the classifier
