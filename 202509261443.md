- minimase the same loss of the regression case 
	- it's a proportional case
	- not actually real one

- the solution is for both 0/1 and LMS
	- there is zone overlapping with 0 loss
	- such there isn't really a solution that minimize both at the same time.

$$E(w) = \lvert  \lvert y - Xw \rvert \rvert^2 $$Where $X$ is a matrix with dimension $l \times n$
- row for each input vector $x_{p}$

- if the target is positive
	- the $x_{i}^T w$ go toward 1
	- the sign is positive
	- no classification error
- if the target is negative
	- the $x_{i}^T w$ go toward -1
	- the sign is negative
	- no classification error

We can't use the $h(x)$, because it's the sign. Therefore $E(w)$ is not a differentiable loss.
- we use $x_{p}^Tw$


---

Imposing the gradient equals to zero we obtain the **normal equation** $$(X^T X)w = X^T y$$ so we can get the hyperparameters $$w = (X^T X)^{-1} X^T y = X^+ y$$ if the $X^T X$ is not singular then we have infinite solution, so we need to choose which one is more suitable.

So for this problem, that's the simplest solution.
