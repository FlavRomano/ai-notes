A training set TR is only one possible realizations from the universe of data.
- different TR
- implies different estimate

The expected prediction error at a point $x$ can be decomposed into: $$E = \text{variance} + \text{bias}^2 + \text{noise}^2$$

---

Given examples $$<x_{i},y_{i}> \quad i=1\dots l$$  where the true function is $$y = f(x) + \varepsilon$$where 
- $\varepsilon$ is Gaussian noise
	- with zero mean $\mu=0$
	- and standard deviation $\sigma$

In linear regression 
- we fit a linear hypothesis $$h(x) = wx + w_{0}$$such as to minimize sum-squared error over the TR $$\sum_{i=1}^l (y_{i} - h(x_{i}))^2$$from this minimization we have a systematic prediction error
	- error does not come from randomness or noise
	- comes from mismatch between
		- true function $f(x)$
		- and the family of functions the model can represent
	- that's exactly what the bias term measures
		- even if we averaged over infinitely many training set
		- this difference would remain

Given a new data point $x$, and assuming that the data points are drawn from a unique probability distribution $P$, what is the expected prediction error? $$E_{P}[(y-h(x))^2]$$
- the expectation is over **all training set** drawn according to $P$
- $y$ is the value for $x$ that could be present in a data set

We can [[202511131704|decompose the expected prediction error ]] in $$E_{P}[(y-h(x))^2] = Var[h(x)] + Bias[h(x)]^2 + \sigma^2$$
- **bias**
	- quantifies discrepancy between true function and $h(x)$ (averaged on data)
	- $H$ small (too rigid model) $\implies$ bias high
- **variance**
	- quantifies the variability 
		- of the response of model $h$
		- for different realizations of the TR
- **noise**
	- the label include random error $$y = f(x) + \text{noise}$$
	- for a given $x$ there are more than one possible prediction $y$
		- even the optimal solution could be wrong
	- does not depends on the model
