For a given training pattern $<x,d>$ we define
- inner loss function $$L(h_{w}(x), d)$$
	- represents the error for a single example
- we want to minimize the loss
	- by adjusting model parameters $w$

---

We compute [[202509281716|empirical loss]]. 

- The **choice of loss function** depends on the nature of the task:
    - Regression → Mean Squared Error (MSE).
    - Classification → 1/0 loss
    - Ranking, clustering, or other tasks → specialized loss functions.
