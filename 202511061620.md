Given the TR set $$T=\{(x_{i}, d_{i})\}\quad\forall i = 1 \dots N$$
We want to
- find the values of the Lagrangian multipliers $$\alpha_{i}\quad \forall i = 1 \dots N$$
- which maximize the objective function $$Q(\alpha) = \sum_{i=1}^N \alpha_{i} - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_{i} \alpha_{j} d_{i} d_{j} \; \underbrace{x_{i}^T x_{j}}_{\text{dot product}}$$

satisfying the constraints
- Lagrangian multipliers between 0 and hyperparameter $C$ $$0\leq \alpha_{i}\leq C\quad \forall i = 1 \dots N$$
- the weighted contributions of the Lagrange multipliers from both positive and negative samples are balanced $$\sum_{i=1}^N \alpha_{i} d_{i} =0$$
	- this keeps the hyperplane **centered between both classes** rather than being dragged toward one side.
	- optimization doesn't favor the positive or negative side of the margin

---

To solve the soft margin we indeed solve this dual problem.

We want to find the best Lagrangian multipliers $$\alpha_{o,i}\quad \forall i = 1 \dots N$$ that maximize $Q(\alpha)$.

Starting from $\alpha_{o,i}$ we can find both optimals $w_{o}$ and $b_{o}$ as $$w_{o} = \sum_{i = 1}^N \alpha_{o,i} d_{i} x_{i}$$ $$b_{o} = d_{j} - \sum_{i=1}^N \alpha_{o,i} d_{i} x_{i}^T x_{j}\quad \text{for } j \text{ s.t } 0<\alpha_{j}<C$$
> The $b_{o}$ condition on index $j$ ensure that we consider only points that defines the margin [[202511061636|see. KTT conditions]].

As before, we will take the sign of the net $g(x)$ $$g(x) = \sum_{i = 1}^N \alpha_{o,i} d_{i} x_{i}^T x + b_{o}$$ $$h(x) = sign(g(x))$$
