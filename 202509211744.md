Given a target function $f$ and a training set $TR$
- a hypothesis $h$ is **consistent** with the $TR$ $$\forall <x,f(x)>\in TR :h(x)=f(x)$$
	- if $h(x) = f(x)$ for each training example $<x,f(x)>$
- we call version space $VS_{H,TR}$ $$VS_{H,TR} = \{h\in H:h \text{ is consistent across all examples in } TR\} \subseteq H$$
	- the subset of hypotheses from $H$
	- consistent with all training examples
