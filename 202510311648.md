Considering **linear functions** (a line or hyperplane, $w^Tx+w_{0}​=0$) for classification, in $\mathbb{R}^2$.

The the VC-dimension, $VC(\mathcal{H})$, is **3**. $$VC(\mathcal{H})=3$$
To find the $VC(\mathcal{H})$, 
- we must find the maximum number of points ($N=p$) 
- that the hypothesis class $\mathcal{H}$ can **shatter**.

If $VC(\mathcal{H})=p$, it means:
1. $H$ shatters at least **one specific set** of $p$ points
2. $H$ **cannot shatter any** set of $p+1$ points

---
## $N=1$

If you take $N=1$ point in $\mathbb{R}^2$:

- There are $2^1=2$ possible labelings
	- (+1) or (−1).
- A line can easily isolate this single point and assign it either label
- H shatters $N=1$ point.

---
## $N=2$
If you take $N=2$ points in $\mathbb{R}^2$:

- There are $2^2=4$ possible labelings.
- For any two distinct points, a line can always be drawn to separate them into any of the four labelings 
	- e.g., (+,+),(+,−),(−,+),(−,−)
- H shatters $N=2$ points.

---
## $N=3$
If you take $N=3$ points in $\mathbb{R}^2$:

- There are $2^3=8$ possible labelings.
- To prove that $VC(\mathcal{H})$ is at least 3, 
	- it is sufficient to find one configuration of three points 
	- which is separable for every labeling.
- If we choose three points that are **not aligned** (forming a triangle), a line (hyperplane) can successfully realize all 8 dichotomies.

![[Pasted image 20251031162758.png]]

*remark*: It is important to realize that 
- not all possible configurations of 3 points can be shattered 
	- e.g., if the three points were perfectly aligned.
- However, the definition requires only the _existence_ of one configuration that works

![[Pasted image 20251031170144.png]]

So $VC(\mathcal{H}) \geq 3$  is proven.

---
## $N=4$
If you take $N=4$ points in $\mathbb{R}^2$:

- There are $2^4=16$ possible labelings.
- To prove $VC(\mathcal{H})<4$, 
	- we need to show that H **cannot shatter any set (configuration) of** 4 **points**.
	- This failure is demonstrated by showing that there is at least one labeling (dichotomy) for 4 points that a single line cannot achieve.
	- This specific labeling (the XOR function) is **not linearly separable**.
- Since the hypothesis class $\mathcal{H}$ (linear functions) failed to realize all 16 possible labelings for this configuration of 4 points, the set of 4 points is **not shattered**.
- Therefore, the VC-dimension cannot be 4, meaning $VC(\mathcal{H})<4$

---

In general, the VC-dim of a class of linear hyperplanes in a $N$-dimensional space is $$VC(\mathcal{H}) = N+1$$
