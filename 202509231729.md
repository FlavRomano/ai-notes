- we use regression when we want to **predict a number** $$d_{p} = f(x_{p}) + e$$
	- $f(x_{p})$ real value function
	- $e$ random error
- $H$ is a set of real valued functions

A common loss function for regression is **squared error** $$L(h_{w}(x_{p}),d_{p}) = (d_{p} - h_{w}(x_{p}))^2$$ The mean over the data set provide the **Mean Square Error**
