Given the TR set $$T=\{(\Phi(x_{i}), d_{i})\}\quad\forall i = 1 \dots N$$
we want to find
- the optimal value of $w$
- which minimizes the objective function $$\psi(w, \xi) = \frac{1}{2} w^T w + C \sum_{i=1}^N \xi_{i}$$

under the constraints 
- positive or zero slack variables $$\xi_{i} \geq 0\; \forall i = 1 \dots N$$
- each data point should be correctly classified, but we allow some errors controlled by slack variable​. $$d_{i}(w^T \Phi(x_{i})) \geq 1 - \xi_{i} \quad \forall i = 1 \dots N$$
