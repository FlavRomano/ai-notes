With the Gradient descent
- we can move toward the **minimum** (steepest descent)
- changing $w$ with $$\Delta w= - \frac{\partial E(w)}{\partial w} = -\nabla E(w)$$the $\Delta$ is the difference between target and output of our model.
- it does a local search
	- starting from a initial weight vector $w_{0}$
	- we modify it iteratively to minimize the error function (steepest descent)

We will move using the following learning rule $$w_{new} = w + (\eta \cdot \Delta w)$$
- $\eta$ give us the step size
	- is also called the *learning rate*
	- rule the speed/stability tradeoff of gradient descending
		- speed achieved with big eta 
			- but we can got unstable quickly
			- oscillation
		- stable algorithm with small eta
			- but it's slow
	- guarantee convergence towards the minimum 
- the $\Delta w$ is negative, because it's the gradient vector of $E(w)$ already with negative
