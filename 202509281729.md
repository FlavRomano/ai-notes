The aim of regression is predicting a numerical value $$d_{p} = f(x_{p}) + e$$
- predicted value is equals to true value plus random error

---

A common loss function for regression is **squared error** $$L(h_{w}(x_{p}),d_{p}) = (d_{p} - h_{w}(x_{p}))^2$$ The mean over the data set provide the **Mean Square Error** $$E(w)=\frac{1}{l} \sum_{p=1}^l (y_{p} - h_{w}(x_{p}))^2$$ ![[Pasted image 20250928173413.png]] $E(w)$ is the mean of the square of the $\color{green}green$ errors.

---

By taking squares 
- we are more forgiving 
	- when the model gets the answer almost right 
- but much less forgiving 
	- when the model is way off. 

Taking squares also makes the mathematics more tractable.
