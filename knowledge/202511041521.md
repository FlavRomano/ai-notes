Given the training set $T$
$$T = \{(x_{i},d_{i})\}, \;i=i..N,\quad \lvert T \rvert = N = \#data $$
we want to find an hyperplane $$w^T x_{i} + b \geq 0\quad d_{i}=+1$$ $$w^T x_{i} + b < 0\quad d_{i}=-1$$
We call **discriminant function** $$g(x) = w^T x + b$$ and our hypothesis, like LTU, is the sign function $$h(x)=sign(g(x))$$

---
The **optimal hyperplane** is
- the hyperplane which maximizes the [[202511041528|margin]] $\rho$ $$w_{o}^T x + b_{o} = 0$$
---
To achieve canonical representation of the hyperplane, we exploit the [[202509261431|scaling freedom property]] 
- we rescale $w$ and $b$
- so that the closest points to the separating hyperplane satisfy $$\lvert g(x_{i}) \rvert = \lvert w^Tx_{i} + b \rvert = 1 $$

We can write 
$$\begin{align}
w^T x_{i} + b &\geq 1\quad d_{i}=+1 \\
w^T x_{i} + b &\leq -1\quad d_{i}=-1
\end{align}$$
or in a compact form
$$d_{i}(w^T x_{i} + b) \geq 1,\quad i=1\dots N$$
