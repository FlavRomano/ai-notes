In machine learning, _online_ means:
- Data arrives continuously, one point at a time.
- You don’t wait for the whole dataset.
- You update your model immediately as each new data point comes in.

In gradient descent online version  $$\frac{\partial E_{p}(w)}{\partial w_{j}} = -2 (y_{p} - x_{p}^T w ) x _{p,j}$$
- we upgrade the weights with the error that is computed **for each pattern**
	- e.g the 2nd pattern output is based on
		- weights already updated from the 1st
- each pattern can thrive the gradient like zig zag
- faster then batch version
