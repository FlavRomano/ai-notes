Given a dataset with iid sample generated from the same Gaussian $$\mathcal{D} = \{ x_{1}, \dots, x_{N} \}$$ we want to find model parameters $\theta = (\mu, \sigma)$ that make the observed data as probable as possible.

Maximizing the log likelihood

$$(\mu_{ML}, \sigma_{ML}) = \arg \max_{\mu,\sigma} \log P(D\mid \mu, \sigma)$$

Under the iid assumption the likelihood is $$P(D\mid \mu, \sigma) = \prod_{j=1}^N P(x_{j}\mid \mu,\sigma)$$ the log makes the optimization easier $$\log P(D\mid \mu, \sigma) = \sum_{j=1}^N \log P(x_{j}\mid \mu, \sigma)$$

We don't have any latent variable $Z$, so this is a very easy because
- fully observable
- just two parameters
- data $x$ comes only from one gaussian
