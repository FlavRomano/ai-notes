The model requires the estimation of
- prior probability of the classes $$P(c=k)\quad 1 \leq k \leq K$$ probability of observing the class $k$ before any attributes 
	- multinomial distribution on class variable $c$
- conditional probability attribute-class (multinomial element) $$P(a_{l} = s \mid c = k)$$ knowing class $k$, how much probable is to observe value $s$ on attribute $a_{l}$
	- multinomial distribution element, the full distribution is $$P(a_{l}\mid c=k)$$
	- for each couple $(a_{l}, c=k)$ we learn a multinomial distribution

The second one is given by $$P(a_{l} = s \mid c= k) = \frac{N_{ls}(k)}{\sum_{s=1}^{S_{l}} N_{ls}(k)}$$ where 
- $N_{ls}(k)$
	- number of samples with class $k$
	- in which the attribute $a_{l}$ is equals to $s$
- $\displaystyle\sum_{s=1}^{S_{l}} N_{ls}(k)$
	- number of samples with class  $k$
	- is a sum because we are computing a probability (normalization to sum up to 1)
