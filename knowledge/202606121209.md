A sequence is a **ordered collection of observations** $y_{t}$ $$y = (y_{1}, \dots, y_{t}, \dots, y_{T})$$ where $t$ is a generic position according to a complete order, usually indicates the time.

The reference population is a set of $N$ iid sequences $$y^{(1)}, \dots, y^{(N)}$$ each with a different length $$T^1, \dots, T^N$$ the order is relevant.

So the key characteristic: **contextual dependence between different positions**.

The easier way to model a sequence from a probabilistic prospective is a Markov chain.
