The readout layer is the **only part** of the network that learns.
- is a standard linear layer connected to the hidden units
- takes the random features $h=f(Wx)$ 
- combines them linearly to produce output $o$ $$o=W^{out}\cdot h$$

So we don't need gradient descent, we can find the optimal $W^{out}$ mathematically in a single step using **Moore-Penrose Pseudoinverse**.

$$W^{out} = H^+ d$$

To avoid overfitting we use ridge regression (L2 regularization) $$W^{out} = (H^TH+\lambda I)^{-1} H^T d$$
