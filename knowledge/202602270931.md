Mathematically the loss function $$d(x_{i}, c(x_{i})) = \lvert \lvert x_{i} - c(x_{i}) \rvert  \rvert^2 $$ that represents average squared error distortion can be written
- as integral $$E=\int \lvert \lvert x_{i} - w_{i^*(x)}\rvert  \rvert^2 \;p(x)\;dx$$ so the integral of the distance weighted by the probability of the data
- as double sum in the discrete version $$E = \sum_{i}^l \sum_{j}^K \lvert \lvert x_{i} - w_{j} \rvert  \rvert^2 \delta_{\text{winner}}(i,j) $$ using a characteristic function $\delta_{\text{winner}}(i,j)$
	- $\delta_{\text{winner}}(i,j)$ is 1 if prototype $j$ is the winner for input $i$, 0 otherwise
	- we only count the error distance **to the winning prototype**

$E$ integrand is not continuously differentiable everywhere
- the winner jumps from one prototype to another as you move $x$
- we can compute derivatives locally (assuming $x$ inside a Voronoi cell) to avoid this problem
