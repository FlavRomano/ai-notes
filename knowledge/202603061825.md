**Maximum A Posteriori (MAP)** is an inference method that selects the single **"most likely" hypothesis** given the data and your prior beliefs.

Once we seen data
- instead of keeping all hypotheses active
- we keep  the highest probability of being true

The model solves this maximization problem $$h_{MAP}=\arg \max_{h\in H} P(h \mid d)$$ using bayes rule $$h_{MAP}=\arg \max_{h\in H} \underbrace{P(d \mid h)}_{\text{likelihood}}\;\underbrace{P(h)}_{\text{prior}}$$ 

MAP balances likelihood and prior
1. How well does this hypothesis explain the data we just saw?
2. How likely was this hypothesis before we saw any data?

Once the model identifies the single winner, it acts as if that hypothesis is 100% true and ignores all others. The prediction for a new value $X$ becomes: $$P(X \mid d) \approx P(X\mid h_{MAP})$$

> if two hypotheses are ==almost equally likely==, MAP arbitrarily 
> - picks the slightly better one
> - ignores the close second.
