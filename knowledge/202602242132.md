Instead of MLP that trains hidden layer, a randomize neural network has fixed weights initialized with random values.

![[Pasted image 20260224215852.png]]

Structurally the hidden layer has a large number of neurons.

$W$ is the hidden layer weight matrix, is random and fixed.

The layer performs a **non-linear embedding**
- it maps the input $x$ to a new feature space $h$ $$h=f(W\cdot x + b)$$ where $f$ is a non-linear activation function
- effectively implements randomized basis expansion $\phi$
