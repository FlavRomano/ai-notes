We want to estimate model parameters $\theta = (\pi, \mu, \sigma)$ of a GMM

The complete log likelihood is $$\log \mathcal{L}_{c}(\theta \mid X,Z) = \sum_{j=1}^N \sum_{m=1}^M \overline z_{jm} \log[\pi_{m} P(x_{j} \mid \mu_{m}, \sigma_{m})]$$

Suppose we have a current estimation $\theta^{(k)}$

$$\theta^{(k)} = (\pi^{(k)}, \mu^{(k)}, \sigma^{(k)})$$

## E-step

Given the actual model, how likely is that $x_j$ was generated from the $m$ component? We are computing the latent variable posterior $$P(z_{j}=m \mid x_{j}, \theta^{(k)})$$

We apply Bayes $$P(z_{j}=m \mid x_{j}, \theta^{(k)}) = \frac{\pi_{m}^{(k)} P(x_{j}\mid \mu_{m}^{(k)}, \sigma_{m}^{(k)})}{\sum_{m} \pi_{m}^{(k)} P(x_{j}\mid \mu_{m}^{(k)}, \sigma_{m}^{(k)})}$$ 

we are computing the **responsibilities**, they measure how much a Gaussian is responsible from the generation of $x_j$.

At this point of E-step we need to compute the $Q$ function, that is the expected value of the complete log-likelihood wrt $Z$ distribution. Instead of putting directly the indicator variables, we put their expected values thank to $Q$ definition. $$\mathbb{E}[\overline z_{jm}] = P(z_{j} = m \mid x_{j}, \theta^{(k)})$$ obtaining the $Q$ function $$Q(\theta \mid \theta^{(k)})) = \sum_{j} \sum_{m} P(z_{j} = m \mid x_{j}, \theta^{(k)}) \log[\pi_{m}^{(k)} P(x_{j}\mid \mu_{m}^{(k)}, \sigma_{m}^{(k)})]$$

## M-Step

We take the $Q$ and maximize it wrt $\theta^{(k)}$  $$\theta^{(k+1)} = \arg \max_{\theta} Q(\theta\mid \theta^{(k)})$$ so we take the derivative $$\frac{\partial Q}{\partial\pi_{m}^{(k)}} = 0, \;\frac{\partial Q}{\partial \sigma_{m}^{(k)}} = 0, \;\frac{\partial Q}{\partial \mu_{m} ^{(k)}} = 0$$

while taking into account of the sum-to-one constraint $$\sum_{m} \pi_{m} = 1$$
