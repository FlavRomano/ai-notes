We got a dataset $$X= \{ x_{1}, \dots,x_{N} \}$$ 
- we assume that exists $M$ gaussians that generated each observation $x_j$
- but we don't know which gaussian generated $x_j$

So we introduce a latent variable $$z_{j} \in \{ 1, \dots, M \}$$ that indicate which component generated $x_{k}$

So we observe $X$ but not $z_{1}, \dots, z_{N}$, we have **incomplete data**
