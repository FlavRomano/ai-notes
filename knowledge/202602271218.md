Fundamental architecture of Recurrent Neural Networks.

Evolution of the MLP by adding **context units**, in order to remember the previous internal state while processing the current input.

![[Pasted image 20260227122234.png]]

1. Input layer $l_{t}$
	- receives the vector at the current time step
2. Hidden layer $x_{t}$
	- contains non-linear activation function
	- it's the processing unit
3. Context layer
	- at every time step
		- the output of the hidden layer gets copied into the context layer
	- at next time step
		- the content oof the context layer is fed back into the hidden layer
4. Output layer $y_t$
	- produces the final prediction based on the current hidden state

The equation for the hidden state is $$x(t) = \tau(l(t), x(t-1)) = f(\underbrace{w^T l(t)}_{\text{current input}} + \underbrace{\hat{w}x (t-1)}_{\text{past context}} + \theta)$$
