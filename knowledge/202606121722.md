The current hidden state $S_{t}$ is calculated from previous hidden state $S_{t-1}$

So a given hidden state $S_{t}$ has useful memory from the past up to time $t$, with that context generates the observation $Y_{t}$.

![[Pasted image 20260612173153.png]]

On the left there is the recursive model because $$S_{t} = f(S_{t-1})$$ is a recursive definition. The current state depends on the previous state, and so on...

When applying the recursive model to a sequence we do **unfolding**, it generates the corresponding directed graphical model.

This idea link 
- probabilistic models (HMM) 
	- $S_{t}$ discrete hidden state
- neural models (RNN)
	- $h_{t}$ hidden layer vector
