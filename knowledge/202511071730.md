Given the TR set $$T=\{(x_{i}, d_{i})\}\quad\forall i = 1 \dots N$$
we want to find
- the optimal value of $w$
- which minimizes the objective function $$\psi(w, \xi, \xi') = \frac{1}{2} w^T w + C \sum_{i=1}^N (\xi_{i} + \xi_{i}')$$

satisfying the constraints
- non-negative slack variables $$\xi_{i},\xi_{i}' \geq 0$$
- the prediction can go up to $\varepsilon$ above the true value
	- plus some extra slack $\xi_p$​ if it exceeds that limit $$d_{i} - w^T \Phi(x_{i}) \leq \varepsilon + \xi_{i}$$
- the prediction can go $\varepsilon$ below the true value
	- plus some extra slack $\xi_p'$​ if it exceeds that limit $$w^T \Phi(x_{i}) - d_{i} \leq \varepsilon + \xi_{i}'$$
