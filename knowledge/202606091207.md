The algorithm assume 
- Markov Condition
- Faithfulness
	- each d-separation in the DAG maps to a conditional independence in the probability distribution
- Causal Suffieciency

Starting from just data (like a thousand samples), the SGS goal is
> understand which variables are connected and in which direction

1. We start with the fully connected Graph, because we have zero prior knowledge.
2. We perform conditional independence testing to cancel out some arcs $$X  \perp\!\!\!\perp  Y \mid Z$$ We got a skeleton, a bunch of nodes with undirected arcs.
3. We find colliders
4. We orient the arrows based on logic rules avoiding new cycles and new colliders

The SGS returns a MEC, the set of all DAGs compatible with the data.

The algorithm is exponential, the bottleneck is the skeleton phase that costs $$O(n^2 \cdot 2^n)$$ is impractical for many variables.
