The error correction in gradient descent is made by a simple correction factor named $\delta$. $$\Delta w_{j} = 2 \sum_{p=1}^l \underbrace{(y_{p} - x_{p}^Tw)}_{\delta_{p}}x_{p,j}$$

- So $\delta_{p}$ is the error
	- how much the predicted output $x_{p}^Tw$ deviate from target output $y_{p}$.
- $x_{p,j}$ is the $j$-th feature of the $p$-th example

By looking at this two values, we can tell if the new value of weight in gradient descent will increase or decrease.
$$w_{new} = w_{new} + \eta * \Delta w_{j}$$

| Case | $x_{p,j}$ | $\delta_p = (y_p - x_p^T w)$ (error) | $\Delta w_j \propto \delta_p x_{p,j}$ | Interpretation                                                                                                                              |
| :--: | :-------: | :----------------------------------: | :-----------------------------------: | :------------------------------------------------------------------------------------------------------------------------------------------ |
|  1   |     +     |                  +                   |                   +                   | Input positive, output too low → **increase $w_j$** → output increases                                                                      |
|  2   |     +     |                  −                   |                   −                   | Input positive, output too high → **decrease $w_j$** → output decreases                                                                     |
|  3   |     −     |                  +                   |                   −                   | Input negative, output too low → **decrease $w_j$** → output increases (since negative input × smaller weight → less negative contribution) |
|  4   |     −     |                  −                   |                   +                   | Input negative, output too high → **increase $w_j$** → output decreases                                                                     |
