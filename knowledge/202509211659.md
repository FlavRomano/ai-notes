Given a particular task, a model should
- capture the relationships among the data
- by a **language**
	- numerical, symbolic...
	- is related to the **representation** used to get knowledge

The model defines the class of functions that the leaning machine can implement
- $H$ hypotheses space
	- the space of all hypotheses that can be output by the learning algorithm
- $h$ is an expression, similar to $f$, in a given **language** that describes the relationship with data.
