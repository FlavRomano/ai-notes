To minimize average reconstruction error function, we can use a classic Stochastic Gradient Descent approach. 
>In the context of unsupervised learning, we call it On-line K-means.

$$E = \sum_{i}^l \sum_{j}^K \lvert \lvert x_{i} - w_{j} \rvert  \rvert^2 \delta_{\text{winner}}(i,j)$$ 

The learning rule for on-line k-means is
- take the derivative of the error with respect to $w_{j}$
- for every single data point $x_i$ $$\Delta w_{i^*} = \eta \delta_{\text{winner}}(i,i^*)(x_{i}-w_{i^*})$$
	- we find the winner $w_{i^*(x)}$
	- and move it slightly closer to $x_i$
		- we only move the winner

Because it's gradient descent
- it suffers from local minima
- depends heavily on where you initialize the centroids
