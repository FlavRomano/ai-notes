Like always we want to compute the log likelihood but this time we got incomplete data because
- we observe $X = \{ x_{1}, \dots, x_{N} \}$
- but not the latent variable $z_{j}\in \{ 1, \dots, M \}$

![[Pasted image 20260611175350.png]]

So the likelihood as-is is incomplete $$\mathcal{L}(\theta\mid X) = \prod_{j=1}^N P(x_{j}\mid \theta)$$ to actually compute $P(x_{j}\mid \theta)$ we have to marginalize it. Because each observation is generated from one of $M$ gaussian distribution.

$$P(x_{j}\mid \theta) = \sum_{m=1}^M P(x_{j}, z_{j} = m \mid \theta)$$ this is necessarily because we need to cancel the latent variable $z_{j}$  by accounting all possible $M$ values.
