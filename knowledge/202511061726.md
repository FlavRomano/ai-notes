The inner product kernel function $k$ is 
- a function that compute directly the dot products in the feature space $$k:\mathbb{R}^{m_{0}}\times \mathbb{R}^{m_{0}} \to \mathbb{R}$$
- is symmetric $$k(x_{i},x)= k(x, x_{i})$$

Not any kernel function computes the inner product in a feature space. [[202511061746|see. Mercer's Theorem]]
## Computing the inner product

Given a non linear mapping function $\Phi$
$$\Phi(\mathbf{x}) = \Phi((x_1, x_2)^T) = (x_1^2, \sqrt{2}x_1x_2, x_2^2)^T$$

Given $\mathbf{x} = (x_1, x_2)^T$ and $\mathbf{y} = (y_1, y_2)^T$ in $\mathbb{R}^2$, we compute $\Phi(\mathbf{x})^T \Phi(\mathbf{y})$ in this way:

$$\begin{align*}
(x_1^2, \sqrt{2}x_1x_2, x_2^2)(y_1^2, \sqrt{2}y_1y_2, y_2^2)^T 
&= x_1^2y_1^2 + 2x_1x_2y_1y_2 + x_2^2y_2^2 \\
&= (x_1y_1 + x_2y_2)^2 \\
&= ((x_1, x_2)(y_1, y_2)^T)^2 \\
&= (\mathbf{x}^T \mathbf{y})^2 = k(\mathbf{x}, \mathbf{y})
\end{align*}$$
---
Let $k_{1}$ and $k_{2}$ be kernels over $\mathbb{R}^{m_{0}}\times\mathbb{R}^{m_{0}}$

The following are kernel function as well:
$$k_{1}(x,y) + k_{2}(x,y)$$ $$\alpha k_{1}(x,y) \quad\forall \alpha \in \mathbb{R}_{+}$$

$$k_{1}(x,y)k_{2}(x,y)$$
