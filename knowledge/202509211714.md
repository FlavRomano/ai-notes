>The **learning algorithm** is the procedure 
>- that **searches the hypothesis space $H$** 
>- to find the hypothesis $h∈H$ 
>	- that best approximates the true function $f$.
>- outputs a model

Given
- data
- task
- model

A learning algorithm perform an (heuristic search)
- through the hypothesis space $H$
	- of the **best hypothesis**
- typically searching $h$ with the minimum error

Search can't be exhaustive
- we can't consider the set of all possible functions
- we need to make assumptions
	- inductive bias
