Estimate an error *analytically* force us to evaluate the hypotheses space $\mathcal{H}$. 

Of course it's not a easy job, but we know VC-dim.

VC-dim is a 
- measure of complexity
	- capacity/expressive power/flexibility
- of a class of hypotheses
	- (also for infinite $\mathcal{H}$)

But the complexity of $\mathcal{H}$ 
- is not simply determined by the number of hypotheses it contains. $$\lvert \mathcal{H} \rvert = \#\text{distinct hypotheses functions within } \mathcal{H}$$
- instead by the *number of distinct instances* that can completely discriminated using $\mathcal{H}$

e.g: Restricting to the classification case

>How much $\mathcal{H}$ can discriminate points?
$$max(\# \text{points that can be correcly classified without error})$$

So how many distinct data points the class $\mathcal{H}$ can perfectly discriminate.

---

Formally the VC-dim of a class of function $\mathcal{H}$ is the 
- cardinality of the biggest set of points in $X$ that can be [[202510311524|shattered]] by $\mathcal{H}$

$$VC(\mathcal{H}) = p$$
that means:
1. $\mathcal{H}$ *shatters* at least one set of $p$ points
2. $\mathcal{H}$ *CANNOT shatters* any set of $p+1$ points

If arbitrarily large (but finite) sets of $X$ can be shattered by $\mathcal{H}$, then $VC(\mathcal{H})$ is infinite.
