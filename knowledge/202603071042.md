> Is used to quantify the "average" outcome of a random process.

The expectation (or expected value) of a function $f: \mathbb{R}\to \mathbb{R}$ is the average value of that function, weighted by the probability of observing different values
- considering univariate continuous random variable $X \sim p(x)$ $$\mathbb{E}_{X}[f(x)] = \int_{\mathcal{X}} f(x)p(x)\;dx$$
- considering discrete random variable $X \sim p(x)$ $$\mathbb{E}_{X}[f(x)] = \sum_{x\in \mathcal{X}} f(x)p(x)\;dx$$

where $\mathcal{X}$ is the set of possible outcomes (target space) of the random variable $X$.
