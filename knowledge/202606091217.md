$$V=\{ X_{1}, \dots, X_{n} \} = \text{observed variables}$$ the skeleton is the undirected graph $G_{S} = (V,E)$ in which
- one arc connects two variable $X_{i}$ and $X_{j}$ only if they are conditionally dependent $$\not\exists Z \subseteq V \setminus \{ X_{i}, X_{j} \} \text{ s.t } X_{i}  \perp\!\!\!\perp X_{j} \mid Z $$
- that's why in SGS we start with the fully connected graph
	- we try conditionally independent test on each arc
	- if the test is true for at least one set $Z$
		- the arc gets deleted
		- and the separation set $Z$ is stored, we need it for the collider orientation phase
