> **Moralization** (aka **"marrying the parents"**) is the specific procedure used to convert a directed graph (like a Bayesian Network) into an undirected graph (like a Markov Random Field).

- If a directed graph only consists of chains or confounders, converting it is easy
	- we just erase the arrows. 
- if we got colliders, it gets tricky
	- if we just erase the arrows and nothing else
		- the rules of Markov Random Fields would not be respected
		- potentially losing dependency that existed in the original directed model
		- e.g ![[Drawing 2026-03-08 18.49.21.excalidraw]] 
			- in the directed model if $X_{2}$ is observed, $X_{1}$ and $X_{3}$ become dependent
			- in the undirected model $X_{1}$ and $X_{3}$ are independent given $X_{4}$, but that's wrong because in a collider that implies blocking the path.
	- we need moralization

1. **Identify common children:** 
	- Look for any node in the graph that has more than one parent (a collider)
2. **"Marry the parents":** 
	- Draw a new undirected edge connecting every pair of parents that share a common child. 
	- They are now formally "married" in the graph structure.
3. **Drop the arrowheads:** 
	- Finally, remove all directional arrows from the original edges
	- turning them into standard undirected edges.

![[Drawing 2026-03-08 18.55.01.excalidraw]]

The resulting "moral graph" is an undirected network where all the original parents in a collider now form a fully connected **clique** (along with their child). 

This ensures that the undirected model correctly preserves the dependency between the parents that occurs when the child is observed.
