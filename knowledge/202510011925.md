Given $l$ training examples $<x_{p}, y_{p}>$ and a loss function $L$ 
- we want to find the weight vector $w$
	- that minimizes the expected loss on $TR$ $$R_{emp}= \frac{1}{l}\sum^l_{p=1} L(h(x_{p}), y_{p})$$
		- if using 0/1 loss provides the number of misclassified patterns
- unfortunately using the 0/1 loss as $L$ is difficult
	- it's a sharp function
	- $E(w)$ will be a not differentiable loss
- we can use the mean squared error Least Squares loss, so like in regression case the least squares $$E(w) = \sum_{p=1}^l (y_{p} - x_{p}^Tw)^2 = \lvert  \lvert y - Xw \rvert \rvert^2 $$ where $X$ is a matrix with dimension $l \times n$, each row is the input vector $x_{p}$.

- if the target $y_{p}$ is positive
	- the $x_{i}^T w$ go toward 1
	- the sign is positive
	- no classification error
- if the target $y_{p}$ is negative
	- the $x_{i}^T w$ go toward -1
	- the sign is negative
	- no classification error

We got two possible solution to get the best $w$ to minimize $E(w)$:
1. [[202510011946|direct approach]]
2. [[202510011954|iterative approach (gradient descent)]]
