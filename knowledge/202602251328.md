Vector Quantization is a framework that
- given a data manifold $V\subseteq \mathbb{R}^n$
	- we want to approximate this huge continuous space
	- using a **finite set** $$w=(w_{1},\dots,w_{K})$$ of **reference vectors** $$w_{i}\in \mathbb{R}^n, i=1,\dots,K\quad \text{weights/prototypes}$$
- for any data point $x\in V$ 
	- we describe it finding its **best-matching** reference vector $$w_{i^*(x)}$$
	- the prototype with **minimum distortion error** (distance) $$\min d(x,w_{i^*(x)})$$

This process divides the space into subregions called **Voronoi polyhedra** $$V = \{ x\in V s.t \lvert \lvert x-w_{i} \rvert  \rvert \leq \lvert \lvert x- w_{j} \rvert  \rvert  \forall j\}$$
- each point in a specific cell 
	- is closest to that cell's centroid
