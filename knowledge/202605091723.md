Now the encoder takes in input a corrupted version of $x$ which is $$\hat{x} = x + \epsilon$$ with $\epsilon$ gaussian noise with small fixed variance $\sigma$ using some noise process is $C(\hat{x} \mid x)$.

The goal is to reconstruct $x$ from $\hat{x}$.

This can be seen as manifold learning.
