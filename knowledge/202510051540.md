1-nn is categorized as

- lazy
	- primary computational work si deferred to the prediction phase
- memory based
- instance based
- distance based

method.

Operates in two main phases:
1. Training phase (Storage)
	- the algorithm simply memorizes the entire training set $$<x_{p}, y_{p}>,\quad p=1..l$$
2. Prediction phase (Inference)
	- given a new input $x'\in \mathbb{R}^n$ the algorithm performs
		1. **find the nearest example**
			- it finds the single training example $x_{i}$ 
			- where $x_{i}$ is the nearest to the new input $x'$
			- finds the index $i$ that minimizes the distance $$i\in[1,\dots,l]\text{ t.c } \min d(x', x_{i})$$
		2. **distance calculation**
			- a common metric is the euclidian distance $$d(x',x_{i})=\sqrt{ \sum_{t=1}^n (x'_{t} - x_{i,t})^2}=\lvert \lvert x'- x_{i} \rvert  \rvert $$
		3. **output prediction**
			- the algorithm then outputs the label $y_{i}$ of that signle nearest training example $x_{i}$
