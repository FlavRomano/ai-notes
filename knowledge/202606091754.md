ML trust only observed data (prone to overfitting), completely ignores any prior belief. If we have little data, ML overfit easily.

MAP instead treats parameter itself as a random variable. Instead of estimating using only data, it combines
1. Evidence from data
2. Prior beliefs

$$\theta_{MAP} = \arg \max_{\theta} P(d\mid \theta) p(\theta)$$

the prior encodes what we believed **before observing data**. We can see the prior as a penalty term from a ML regularization prospective.

Geometrically ML cares about the likelihood peak, with MAP the peak may shift because the prior influences the result.

ML and MAP become similar as the amount of data grows.
