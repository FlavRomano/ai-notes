Hidden state are usually discrete $$S_{t}\in \{  1\dots C \}$$

We got 
- an **initial distribution** $$\pi_{i} = P(S_{1} = 1)$$ probability that the chain starts with state $i$.
- a **transition matrix** $$A_{ij} = P(S_{t} = i \mid S_{t-1} = j)$$ probability of jumping from state $j$ to $i$
	- thanks to the **stationarity assumption** 
		- the same matrix $A$ is used for each time instant
	- transition rules doesn't change through time.
