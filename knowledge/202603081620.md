![[Drawing 2026-03-08 16.07.07.excalidraw]]

- red path
	- we got a chain with the middle node observed
	- the middle node blocks the path
	- so it is in $Z$
- green path
	- we got a chain with the middle node observed
	- the middle node blocks the path
	- so it is in $Z$

Since **both** paths between $Y_1$ and $Y_2$ are blocked by nodes in set $Z$, the two nodes are d-separated by $Z$. $$Y_{1} \perp\!\!\!\perp_{\mathcal{G}}  Y_{2} \mid Z$$
This means that $Y_1$ and $Y_2$ are conditionally independent given $Z$ ($Y_1, Y_2 \mid Z$).
