Soft-max is a generalization of the logistic function
- maps a vector $x\in \mathbb{R}^K$
- into a vector $z\in \mathbb{R}^K$ in which each component
	- is positive $z_{i}>0$
	- has values between $0$ and $1$ $$z_{i}\in (0,1),\quad \sum_{i}^K z_{i} = 1$$

So normalize a vector into a probability distribution.

Is often used as activation function on output layer in MLP classifiers.

![[Pasted image 20260227101513.png]]

It is also used in K-means to mitigate local minima problem.
