The mode is **the most frequently occurring value**. 
- For a discrete random variable the mode is defined as **the value $x$ having the highest frequency of occurrence**
- For a continuous random variable, the mode is defined as a **peak in the density $p(x)$**
	- a particular density $p(x)$ may have more than one mode 
		- e.g bimodal ones
	- there may be a very large number of modes in high-dimensional distributions
	- finding all modes of a distribution can be challenging
