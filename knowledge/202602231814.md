Learning in neural network relies on chain rule of backpropagation.
- multiplying gradient
- layer by layer

If weights are large >1
- repeated multiplication causes gradients to grow exponentially
- cliff

![[Pasted image 20260223181618.png]]

Gradient descent has catapult effect on cliff, because
- the gradient is massive
- so the update step becomes massive

We mitigate this problem with gradient clipping
