The E-Step is the first phase of Expectation-Maximization algorithm. In this phase the goal is compute the expected log likelihood.

Unfortunately we can't compute that directly because $$\mathcal{L}(\theta\mid X,Z) = P(X,Z\mid \theta)$$ requires marginalization and is not easy $$\begin{aligned}
\log P(X \mid \theta)
&= \log \sum_{Z} P(X,Z \mid \theta) \\
&= \log \sum_{Z} P(Z \mid X,\theta^{(k)})
    \frac{P(X,Z \mid \theta)}
         {P(Z \mid X,\theta^{(k)})}
\end{aligned}$$

because is not easy to compute the derivative (we got a log of sum).

So given the current estimate of model parameters $\theta^{(k)}$ 
- we compute posterior for each latent variable 
- to estimate a proxy function for the complete log likelihood $$Q^{(k+1)}(\theta\mid\theta^{(k)}) = \mathbb{E}_{z\sim P(Z\mid X,\theta^{(k)})}[\log P(X,Z=z \mid \theta^{(k)})]$$ that works like a weighted average of the complete log-likelihood over all possible latent variables $Z$
	- we do log first then compute the mean
	- easier then the log of sum mathematically
