> MAP is a **regularized version** of ML (Maximum Likelihood), because
> - adds a penalty term that discourages certain parameter values
> - typically overly complex ones

Maximum Likelihood chooses $$\theta_{ML} = {\arg \max}_{\theta} P(d\mid \theta)$$ only cares about fitting the observed data

MAP adds a prior $$\theta_{MAP} = \arg \max_{\theta} P(\theta\mid d)$$ using bayes theorem $$P(\theta\mid d) = \frac{P(d\mid \theta) P(\theta)}{P(d)}$$ since $P(d)$ does not depend on $\theta$ 
$$\theta_{MAP} = \arg \max_{\theta} P(d\mid \theta) P(\theta)$$ taking logs $$\theta_{MAP} = \arg \max_{\theta} [\log P(d\mid \theta) + \log P(\theta)]$$

rewriting as a minimization

$$\theta_{MAP} = \arg \min_{\theta} [- \log P(d\mid \theta) - \log P(\theta)]$$

- $- \log P(d\mid \theta)$ is the **ML LOSS**
- $P(\theta)$ is the penalty term
	- is **LARGE** when a parameter value has low prior probability
	- MAP discourages choosing it
