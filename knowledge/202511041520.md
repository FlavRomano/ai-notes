Assuming hard margin SVM with:
- linear separable problems
- no errors in the data
	- hard margin doesn't admit patterns violating the margin (e.g classification error)

the ingredients are:
- [[202511041521|separating hyperplane]]
- [[202511041528|separation margin]]
- [[202511041545|support vector]]
- [[202511041548|distance to the hyperplane]]

It's a [[202511041637|quadratic optimization problem]]:
- finding the optimal values of $w$ and $b$
- to **maximize the margin** $\rho$

The [[202511041636|solution]] computational cost problems scales with the size of the input space $m$.

From the KT-conditions applied to the primal form of the problem, in the saddle point of $J$:

$$\alpha_{i}(d_{i}(w^T x_{i} + b) - 1) = 0 \quad \forall i = 1 \dots N$$

so we discover that
- if a Lagrangian multiplier is positive$$\alpha_{i} > 0$$
	- then the margin boundary $d_{i}(w^Tx_{i} +b) = 1$ 
	- and $x_{i}$ is a support vector
- if $x_{i}$ is not a support vector
	- then $\alpha_{i} =0$

The hyperplane **depends only from support vectors**. So we can restrict the computation to the support vectors $N_{s}$.

To obtain the optimal Lagrangian Multipliers  we solve the [[202511041714|dual problem]] $$\alpha_{o,i}\quad i=1\dots N$$ so now we can compute both optimal $w_{o}$ and $b_{o}$ $$\begin{align}
w_{o} &= \sum_{i = 1}^N \alpha_{o,i}d_{i}x_{i} \\
b_{o} &= 1- w_{o}^T x^{(s)} \\
&=1 - \sum_{i = 1}^N \alpha_{o,i}d_{i}x_{i}^T x^{(s)}
\end{align}$$

- Just from the Lagrangian multipliers we can compute the optimal bias $b_{o}$, 
- we don't need to calculate $w_{o}$, in fact the decision surface is given from $$\begin{align}
w_{o}^Tx + b_{o} &= 0 \\
\iff \sum_{i = 1}^N \alpha_{o,i}d_{i} \; \underbrace{x_{i}^T x}_{\text{dot product}} + b_{o} &= 0
\end{align}$$
So given input patter $x$
1. compute discriminate function (net) $$g(x)= w_{o}^Tx + b_{o} = \sum_{i = 1}^N \alpha_{o,i}d_{i} \; x_{i}^T x + b_{0}$$
2. classify $x$ with the sign $$h(x)=sign(g(x))$$

There are relevant considerations about the [[202511041752|generalization in hard margin SVM]] that relates VC-dim minimization to the minimization of $\lvert \lvert w \rvert \rvert$ $$min\;\lvert \lvert w \rvert  \rvert \iff min\;VC\text{-dim} \iff max \;\rho$$
So even if the problem for linearly separable data has solution, the strategy of maximizing the margin $\rho$
- impose an unique solution
- only using few training point
	- support vectors (the one on the margin)
	- not the other points (far from the margin)
		- don’t affect the final model at all.

|**Pros (Nice)**|**Cons (Less Nice)**|
|---|---|
|✅ The model depends **only on a few “important” points** (the support vectors).|⚠️ The model depends **heavily on a few points** — if they’re noisy, the boundary may shift badly.|
|✅ **Ignores points far from the margin**, which simplifies computation and improves efficiency.|⚠️ **Sensitive to outliers or mislabeled samples** near the margin.|
|✅ Leads to a **sparse solution** — only support vectors matter.|⚠️ **Hard to detect** if boundary points are unreliable without additional checks or preprocessing.|
|✅ Reduces risk of **overfitting** since it doesn’t try to perfectly fit all points.|⚠️ Can **underperform** when the boundary region is noisy or not well defined.|
|✅ Geometrically elegant — the decision boundary is determined by the **critical edge points** only.|⚠️ The assumption that the **margin points are representative** may not always hold in real-world data.|
