Given a function of several variables $f:\mathbb{R}^n \to \mathbb{R}$ we call **gradient** the generalization of the derivative to $f$.

- We find the gradient of the function $f$ with respect to $x$ 
	- by **varying one variable at a time** and keeping the others constant.
	- as known as **partial derivatives**
- The gradient is **the collection of these partial derivatives**

We define the gradient vector as a row vector because 
1. we generalize the gradient to vector valued functions $f:\mathbb{R}^n\to\mathbb{R}^m$, then the gradient becomes a matrix
2. it's easy to apply the multi-variate chain rule
---
Given a vector valued function $f:\mathbb{R}^n \to \mathbb{R}^m$ and a vector $x = (x_1,\ldots,x_n)^T\in \mathbb{R}^n$ the corresponding vector of function values is given as $$f(x) = \begin{pmatrix}
f_{1}(x) \\
\vdots \\
f_{m}(x)
\end{pmatrix} \in \mathbb{R}^m$$
Therefore we can view $f$ as a **vector of functions** $\begin{pmatrix}f_{1}, \dots, f_{m}\end{pmatrix}^T$ that map onto $\mathbb{R}$
