A CPT is the standard way to represent the parameters of a **Discrete Bayesian Network**. 

Each node in the network 
- representing a random variable 
- is associated with a CPT that quantifies the relationship between 
	- that node 
	- and its parents.

The CPT defines the **Local Conditional Probability** of a variable $Y_i$ given its parents $pa(Y_i)$. 

In a Bayesian Network, the joint probability of all variables is calculated by multiplying these local CPTs together:
$$P(Y_1, \dots, Y_N) = \prod_{i=1}^{N} P(Y_i \mid pa(Y_i))$$

The "complexity" of a Bayesian Network is determined by the size of these tables. 

*   **$L$**
	* The maximum number of ingoing edges (parents) to a node.
*   **$k$**
	* The number of distinct values each discrete variable can take.

The total number of parameters is at most $$N \cdot (k-1)^L$$

Without independence, representing a joint distribution requires $k^N - 1$ parameters (exponentially large).

By using conditional independence (the Local Markov Property), we only need to store the CPTs for each node.
> The sparser the network, the less complex the parameters.

If a node has fewer parents (smaller $L$), 
- the CPT is much smaller
- making the model easier to learn and perform inference on.
