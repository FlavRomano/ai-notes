Given a solution:
- we want measure the **absolute gap** of that solution $$A(x) = f(x) - f_{*} (\geq 0)$$
	- it gives a direct measure of how far the current solution is from the theoretical best.
	- Especially useful when values are small or when exact precision is needed.
	- It helps determine **when to stop algorithms**
	- it's not very useful
		- because we can scale the objective function at any number we want
		- so in absolute gap **scale matters**, and we don't want that
- the **relative gap** is scale invariant (normalized measure), meaning that we don't consider any scale factor $$R(x) = \frac{f(x) - f_{*}}{\lvert f_{*} \rvert } = \frac{A(x)}{\lvert f_{*} \rvert } (\ge 0)$$
	- we divide the absolute gap by the optimal value
	- if the $f_{*}$ is zero the relative gap is not defined
		- the absolute gap is simplier
	- It allows for comparison across problems of different sizes and magnitudes.
