The gradient descent is an iterative algorithm
- with the $-\nabla$ of the error $E(w)$
- with that we can tune the $w$ 
	- in a way that can minimize the loss

The learning rule is based on the delta changing $$w_{new} = w + \eta  \cdot \Delta w$$
- eta give us the step size
	- also known as learning rate
	- rule the speed/stability tradeoff
		- speed achieved with big eta 
			- but we can got unstable quickly
			- oscillation
		- stable algorithm with small eta
			- but it's slow
	- guarantee convergence towards the minimum 
- the $\Delta w$ is negative, because it's the gradient vector of $E(w)$ already with negative

We got two different versione
- batch
- online
	- aka stochastic
	- each pattern can thrive the gradient like zig zag
	- this is faster then batch version.
