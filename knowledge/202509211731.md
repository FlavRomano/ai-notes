- A boolean function on $n$ inputs maps from $f:\{0,1\}^n\to\{0,1\}$
	- There are $2^n$ possible input combinations.
	- For each input combination, the function can output either 0 or 1.
	- So the total number of distinct boolean functions is: $$\lvert H \rvert = 2^{2^n}$$
- Suppose we want to learn the boolean function $f$
- One way is to use a **lookup table**
	- for every possible input (all combinations in $H$), we store the output.
- This perfectly represents any boolean function, since you just “look up” the answer.
- The problem is that the table grows **exponentially** with $n$. 
	- The model doesn’t generalize
		- it just memorizes.
