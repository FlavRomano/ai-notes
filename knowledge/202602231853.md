In dropout for each mini batch $mb$ the algorithm generates a **random binary mask vector** for each layer. The probability is ruled by a fixed hyperparameter before training:
- typically hidden layers units have less chance to stay $$p_{\text{hidden}}=0.5$$
- instead input layers units have greater chance $$p_{\text{input}}=0.8$$

The neuron's activation is multiplied by this mask
- if the mask is 0
	- neuron is removed for that iteration

Backpropagation only updates the weights of the units **not dropped**.

Units become less dependent from each other
- single units learn features better
- generalization improvement

The removed units are then reinserted into the network, with their original weights.

> Effectively trains the ensemble consisting of
> - all subnetworks 
> 	- that can be formed by removing non-output units
> 	- from the base network
