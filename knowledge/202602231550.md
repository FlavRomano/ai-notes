Universal approximation theorem states that
- a neural network with one single hidden layer, with enough neurons
	- shallow network
- can approximate any function

However is not always the most efficient solution. In fact that's what the No-flattening theorem states
> while you can flatten a deep network into a shallow one, the number of neurons required usually grows **exponentially**.
