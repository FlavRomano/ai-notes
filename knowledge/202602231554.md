Consider the **Parity Function**.
- $N$ binary inputs
- outputs
	- 1 if there is an odd number of 1s
	- 0 otherwise

Observe two approches

## Shallow approach
Implementing this with a shallow net
- force to memorize specific patterns
- to cover all cases for $N$ inputs we need $$2^{N-1}+1 \text{ gates}$$

the size of the network grows **exponentially** with the input size.

## Deep approach
With $\log N$ layers the situation improve
- we compare inputs in one layer
	- then compare the results in next layer
- we reuse the computation at each level

The size of the network grows linearly.
