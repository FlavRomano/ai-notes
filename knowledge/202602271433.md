Training RNNs is slow and difficult due to gradients. 

So, everything could be easier if we don't train the recurrent part. But how?

We use a **randomly connected** recurrent network
- we fix these weights $\hat{W}$
	- don't train them
- we only train the output layer

![[Pasted image 20260227143622.png]]

An Echo State Network is the implementation of this concept, it consists in a 
- large reservoir of sparsely connected RNNs
	- untrained after random initialization
- readout layer of linear units
	- trained using ridge regression closed form solution

We just need the readout layer to interpret the hidden patterns.
