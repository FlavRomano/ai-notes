> Finding conditional independence in an MRF is much simpler than in a Bayesian Network. There are **no colliders**.

Two sets of nodes $A$ and $B$ are conditionally independent given a set $C$ $$A \perp\!\!\!\perp B \mid C$$ if **all paths** connecting any node in $A$ to any node in $B$ pass through at least one node in $C$. 

![[Drawing 2026-03-08 18.11.52.excalidraw]]

> Essentially, if set $C$ physically "blocks" all routes between $A$ and $B$ in the graph, they are independent given $C$.

Because separation is purely based on direct paths, the **Markov Blanket** of a node in an MRF
- consists of **all and only its immediate neighbors**

Knowing a node's neighbors completely shields it from the rest of the network.
