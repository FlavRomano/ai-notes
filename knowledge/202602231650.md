An autoencoder is
- a neural network trained to copy its input to its output
- **unsupervised** learning model
	- does not require labels
	- the target is the input data itself

![[Pasted image 20260223165124.png]]

Consists of two parts (encoder + decoder)
1. Encoder
	- takes the input data $x$
	- compresses it into a hidden representation $$h=f(x)$$
2. Hidden Layer (latent space)
	- represents the learned compressed representation of the input
	- typically has lower dimension than the input
		- in order to discard noise
		- and learn only the most essential patterns 
			- AKA **salient feature**
			- the one required to reconstruct the inputs
3. Decoder
	- takes the hidden $h$ and expands it back to the original dimensions
	- produces a reconstruction $r$ $$r=g(h)$$

| type of autoencoder | hidden layer size        | noise | implications                  |
| ------------------- | ------------------------ | ----- | ----------------------------- |
| **undercomplete**   | smaller than input layer | less  | extracts salient correlations |
| **overcomplete**    | larger than input layer  | more  | corrupt input with noise, the model learn the robust structure of the data                              |

The aim is minimize the reconstruction error
