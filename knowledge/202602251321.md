Clustering is a usual task of unsupervised learning.

Given a set of sample $<x>$ we want to partition data into clusters.
> A cluster is a subset with containing data similiar to each other,
> Each cluster has a centroid
> - the most representative sample in the cluster

A clustering algorithm decides the grouping based on a metric
- a metric enables pattern proximity
- this is called **metric dominance**
	- if you change the metric, the clustering changes
