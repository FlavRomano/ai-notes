Instead of the simple TDNN approach based on a sliding window of inputs, we can maintain a **state**.

The state at the beginning is $x(0)=0$

The state at time $t$ of $x$ is $$x(t) = \tau(l(t), x(t-1))$$ depends on
- the current input $l(t)$
- and the previous state $x(t-1)$

> RNN can theoretically hold infinite memory duration (though limited by precision), summarising the entire subsequence history.

![[Pasted image 20260227115118.png]]

$\tau$ is the state transition function $$x(t) = \tau(l(t), x(t-1)) = f(w^T l(t) + \hat{w}x (t-1) + \theta)$$ where
- $f$ is the sigmoidal activation function
- $\hat{w}$ is the recurrent weight
	- weights the memory
- $\theta$ is the bias

> This is **adaptive encoding**, the network learns how to **compress** the past into the state vector
