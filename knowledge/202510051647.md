To be more realistic, K-nn use the parameter $l/k$
- it acts as a measure of the model's flexibility or complexity
	- analogous to the VC-dimension concept or the polynomial degree $M$
- as $K$ decreases (low $K$)
	- $l/k$ increases
		- high flexible model
		- model adapts closely to the $l$ data points
	- the model moves toward the overfitting zone
- as $K$  increases (high $K$)
	- $l/k$ decreases
		- prediction relies on a large portion of the entire training set
		- significant smoothing over the neighborhood
	- the model moves toward the underfitting zone

This shows that the model complexity in K-nn 
- is not just about the hyper-parameter $K$
- but how $K$ relates to the size of training set

---
**Data:** 200 points generated in a two-dimensional space ($\mathbb{R}^2$), 
- 100 points belonging to each of two classes

| K Value                             | Effective Complexity ($l/K$) | Training Error (Green Curve) | Test Error (Red Curve) | Model Behavior                                                                                                                                                             |
| ----------------------------------- | ---------------------------- | ---------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **$K=1$**                           | **Very High**                | **Zero Error**               | **High Error**         | **Overfitting**. The model is too flexible, fitting noise and creating irregular, noisy boundaries.                                                                        |
| **Intermediate $K$** (e.g., $K=15$) | **Medium/Optimal**           | Low, but $>0$                | **Minimum Error**      | **Best Trade-off** (Optimal Generalization). This value performs a smoothing operation that provides a test error close to the optimal **Bayes Error Rate** (purple line). |
| **Very High $K$**                   | **Very Low**                 | High                         | High                   | **Underfitting**. The model is too rigid, averaging over too many distant points and failing to capture local details.                                                     |
