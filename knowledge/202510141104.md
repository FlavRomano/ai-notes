- linear function
	- for regression
- threshold or step
	- perceptron/ltu
- sigmoidal
	- resemble the threshold function but 
		- is differentiable
		- is smoothed
	- is a non linear function
	- is bounded 
	- we can activate the idea of gradient descent

---

We have three type of sigmoidal
1. logistic
	- with the $a$ we can tune the behaviour
		- where 0 is the case of the linear
		- where infinity is the case of LTU
	- regulates the slope of the curve
	- is not symmetric
2. hyperbolic tangent
	- is symmetric
	- the interval is from -1 and +1
		- interesting when modeling -1/+1 loss
	- can be obtained from the logistic function by doubling it and subtract 1 to center the origin.
	- the threshold is in 0
3. Radial basis functions
	- corresponds to the gaussian function
	- typically the input is not the net $w^Tx$
		- instead $$\lvert \lvert  w - x_{\text{input}} \rvert  \rvert $$
4. Tangent like
	- is for efficient computation
	- use binary shift operation
5. ReLU (Rectified Linear Unit)
	- important in Deep Learning
	- not differentiable in the origin
		- to solve this we use Softplus
		- smooth approximation

The accuracy of the model is not related to the activation function. There isn't any best one.
