A phenomenon 
- measured by one number $y$
	- output
- depend on a vector $x = (\begin{matrix}x_{1}, \dots , x_{n}\end{matrix})$ of other numbers
	- input

We don't understand the phenomenon, but we can measure it.

We have a large set of observations $$(y^1, x^1), \dots, (y^m, x^m)$$
Now we want to build a model. To build it the form of the model can be fix with a fixed number of parameter to fit with data. 

So we can assume that my model will be a linear function $$y = \sum_{i=1}^n w_{i} x_{i} + w_{0} = wx + w_{0}$$
- I need to choose $w$ right to find good value for $y$
The underlying system will not linear, but I find good parameters that can approximate the function.

--- 
We cannot hope that this thing can work every time. 
- we can't always find values of the parameter that reproduce real
- we can find values of the parameter that fit best
	- easy to solve problem
---
Find $w$ for which it is less untrue 

$$y = \begin{pmatrix}y^1 \\ \vdots \\ y^m\end{pmatrix} , X = \begin{pmatrix}1 & x^1 \\ \vdots & \vdots \\ 1 & x^m\end{pmatrix}$$ $$min_{w} \mathcal{L}(w) = \lvert \lvert y-X w \rvert \rvert$$

- $Xw$ is the output of the function given the choice of parameters $w$
- I want to $Xw$ to be as close as possible to the real output $y$
- So the model looks like the actual data if we minimize this error
---
By simplification $$X^T X w = X^T y \implies w = (X^TX)^{-1}X^Ty$$
