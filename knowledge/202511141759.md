The core idea is
- train models **sequentially**
	- each new model
		- focuses on the mistakes of the previous one
- in the next iteration
	- wrong (misclassified/poorly predicted) samples get **higher weights**
- the aggregation is via
	- weighted voting
	- or summation of model outputs

The effect is
- bias reduction
	- later models **correct** earlier ones
- can also control variance
	- if done properly

The training happens sequentially, because models depend on each other.

---

In AdaBoost
- each base classifier
	- gets a weight **proportional** to its accuracy
	- later ones correct the misclassified instances $$\text{weight}_{i}\propto \text{accuracy}_{i}$$
