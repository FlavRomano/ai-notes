Given the whole training dataset, assuming iid samples $$\mathcal{D} = \{ (x_{j}, c_{j}) \}^D_{j=1}$$ the likelihood of the dataset is $$\mathcal{L}(\theta \mid \mathcal{D}) = \prod_{j=1}^D P(c_{j}) \prod_{l=1}^L P(a_{lj}\mid c_{j})$$

We introduce indicator variables to simplify the log likelihood writing 

$$z_{jk} = \begin{cases}
1 &\text{if } x_{j} \text{ is classified }k \\
0 &o/w
\end{cases} \quad t_{j}^{ls} = \begin{cases}
1 &\text{if } a_{jl} \text{ has value }s \\
0 &o/w
\end{cases}$$

The likelihood become $$\mathcal{L}(\theta\mid \mathcal{D}) = \prod_{j=1}^D \prod^K_{k=1} P(c=k)^{z_{jk}} \prod_{l=1}^L \prod_{s=1}^S P(a_{l} = s \mid c=k)^{t_{j}^{ls} z_{jk }}$$ so
- if the sample $j$ belongs to class $k$, then $z_{jk}=1$
- if attribute $l$ of sample $j$ has value $s$, then $t_{j}^{ls}=1$
- any other term is ignored, because with indicator 0 their value is 1

By introduction of logarithm we got $$\log \mathcal{L}(\theta\mid \mathcal{D}) = \sum_{j=1}^D \sum^K_{k=1} z_{jk} \log P(c=k) + \sum_{j=1}^D \sum_{k=1}^K z_{jk } \sum_{l=1}^L \sum_{s=1}^S t_{j}^{ls} \cdot \log P(a_{l} = s \mid c=k)$$

Maximizing the log likelihood under normalization constraints 

$$\sum_{k=1}^K P(c=k) = 1$$ 
$$\sum_{s=1}^S P(a_{l} = s \mid c= k) = 1$$

we obtain the ML estimators

- classes' prior $$P(c=k) = \frac{\sum_{j=1}^D z_{jk}}{D} = \frac{N(k)}{D}$$ where $N(k)$ is the number of samples that belongs to class $k$
- probability attribute-class $$P(a_{l} = s \mid c= k) = \frac{\sum_{j=1}^D z_{jk} t_{j}^{ls}}{\sum_{j=1}^D \sum_{s=1}^{S_{l}}} =\frac{N_{ls}(k)}{\sum_{s=1}^{S_{l}} N_{ls}(k)}$$
	- $N_{ls}(k)$ is the number of samples that belongs to class $k$ where attribute $a_l$ is equal to $s$
	- $S_{l}$ is the number of possible values for attribute $a_{l}$

Essentially in Naive Bayes Maximum Likelihood is just counting frequencies.
