1. Train one autoencoder to compress the data
2. Delete the decoder, keep the encoder
3. Use encoder output $h_1$ as input for a second autoencoder

![[Pasted image 20260223170903.png]]

By stacking encoders, we initialize a deep network with weights 
- that already understand the structure of the data
- effective pre-training technique
- last layer can be substitute 
	- allows transfer learning
