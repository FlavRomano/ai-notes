Regression is
- a type of **supervised learning** 
- the model is trained with labeled example $$<in,out> = <x, d>$$ where target $d$ are numerical data, so $f(x)\in \mathbb{R}$ are continuous data
- the model wants to find a curve that fits $x$ and unseen data $x'$
