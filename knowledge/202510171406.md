Changing the update rule, we improve the algorithm and yet the gradient remains unchanged.

- momentum
	- conceptually made for the batch version (is a must)
	- heavy ball method
	- constant $\alpha$
	- the movement did before with w_old influence partially the movement of the new $w$
		- if we encounter the same direction of the gradient
		- we accumulate inertia
		- we move faster and faster in plateaus
		- decrease oscillations positive negative, because decrease the inertia and become slower and slower stabilizing to one point then.
	- it's a sort of inertia
	- in the online version the momentum is related to the last pattern
		- the movement is effected by the patterns
		- is not a must for the online version
		- idem for the minibatch
	- nesterov
		- evaluate gradient after the momentum is applied
			- we first apply the momentum
			- then evaluate the new gradient at this interim point
		- improve the rate of convergence for batch mode


- variable learning rate
	- we start with an high learning rate eta
	- when we are close to the target we low the learning rate
		- then stop and use fixed small eta
	- it's a good heuristic but there are a lot of hyperparameters

- adaptive learning rates
	- the eta is automatically adapt
	- even separate eta for each weight of the network
