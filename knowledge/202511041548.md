We call $r$ the distance between
- $x$ 
- and the optimal hyperplane $$w^T_{o} x + b_{o} = 0$$

Recalling to the [[202509261431|scaling freedom]], $w_{o}$ is a vector **orthogonal to the hyperplane**

![[Pasted image 20251104155207.png]]

so, given a point $x_{p}$ that *lies on the hyperplane* $$g(x_{p}) = 0$$ 

we can compute $x$ as $$x = x_{p} + r \frac{w_{o}}{\lvert \lvert w_{o} \rvert  \rvert }$$
Evaluating the discriminate function $g(x)=w_{o}^Tx + b_{o}$ we obtain $$\begin{align}
g(x) &= \underbrace{w_{o}^T x_{p} + b_{o}}_{g(x_{p})} + w_{o}^T r \frac{w_{o}}{\lvert \lvert w_{o} \rvert  \rvert } \\
&= \overbrace{g(x_{p})}^{=0} + r \frac{\overbrace{w_{o}^T \cdot w_{o}}^{\lvert \lvert w_{o} \rvert  \rvert^2 }}{\lvert \lvert w_{o} \rvert  \rvert } \\
&= r \frac{\lvert \lvert w_{o} \rvert  \rvert^2}{\lvert \lvert w_{o} \rvert  \rvert } = r \lvert \lvert  w_{o} \rvert  \rvert 
\end{align}$$ so the distance $r$ is equals to $$r = \frac{g(x)}{\lvert \lvert w_{o} \rvert  \rvert }$$
