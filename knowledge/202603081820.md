> In Bayesian Networks, we multiply conditional probabilities ($P(Y \mid Parents)$). In MRFs, there are no parents, so we use cliques.

A clique is a subset of nodes where every node is directly connected to every other node by an edge (fully connected).

![[Drawing 2026-03-08 18.22.32.excalidraw]]

A **maximal clique** is a clique where we **cannot add any other node to it** without breaking the fully connected rule.

Given $X=X_{1},\dots,X_{N}$ as the random variables associated to the $N$ nodes in the undirected graph $\mathcal{G}$.

The joint probability in an MRF is calculated by multiplying **potential functions ($\psi$)** defined over these maximal cliques ($C$):
$$P(X) = \frac{1}{Z} \prod_{C} \psi(X_C)$$

![[Drawing 2026-03-08 18.36.58.excalidraw]]

*   **$\psi(X_C)$**
	* the potential function for the variables in maximal clique $C$. 
	* it measures the compatibility or "energy" of the states of those variables.
*   **$Z$ (The Partition Function):** 
	* Because potential functions do not naturally sum to 1 like regular probabilities, we must divide the whole product by $Z$, a normalizing constant.

**The Bottleneck:** 
* calculating $Z$ is the **computational bottleneck** of undirected models.  $$Z = \sum_{X} \prod_{C} \psi(X_{C})$$
* If you have $N$ discrete variables with $K$ values each
	* calculating $Z$ takes $O(K^N)$ operations, which becomes intractable very quickly.
