Given two set of variables $X$ and $Y$, 
- they are independent of each other
- provided the state of the set of variable $Z$

$$p(X,Y\mid Z) = p(X\mid Z)p(Y\mid Z)$$

if $x$ is conditionally independent of $y$ given $z$, this means that, 
- given $z$
	- $y$ contains no additional information about $x$
	- knowing $x$ does not tell me anything more about $y$
