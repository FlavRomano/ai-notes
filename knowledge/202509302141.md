We want to estimate a real-value function based on a finite set of noisy samples $$<x, f(x) + \text{noise}>$$

Univariate because we start
- with one input variable $x$
- and with one output variable $y$

We assume a model $h_{w}(x)$ expressed as $$out=w_{1}x + w_{0}, \quad w_{i} \in \mathbb{R}$$
- this is a **linear hyphotesis**, 
	- it's a straight line
- $w_{i}$ are called **free parameters** (weights)
	- must be learned
	- $w_{0}$ is called **bias** or **threshold**
		- because it's the only term independent from the input $x$.

---

- The training phase
	- aims to **find good values of $w$**
	- such that result in the best data fitting 
		- straight line approximating the data points
		- minimizing the empirical loss $R_{emp}$ on TR
			- using Least Mean Square
