We don't know latent variable $Z$ but is fundamental for computing complete log likelihood $$\mathcal{L_{c}}(\theta\mid X,Z) = P(X,Z\mid \theta) = \underbrace{P(Z\mid X,\theta)}_{\text{posterior}} P(X\mid \theta)$$ 

The expectation-maximization try to estimate $Z$, the algorithm is divided in two step:

At iteration $k$ we estimated model parameters $\theta^{(k)}$
1. E-Step
	- given the current model $\theta^{(k)}$ how likely is it that each possible value of $Z$ is the correct one? 
		- we compute the posterior $P(Z\mid X,\theta^{k})$
		- we then use each posterior value in $Q$
	- use the current estimate of model parameters $\theta^{(k)}$ to estimate a proxy function of the complete likelihood called $Q$
		- is an easier version of the likelihood in which at point $\theta^{(k)}$
			- both $Q$ and $\mathcal{L}_{c}$ touches ![[Pasted image 20260610194834.png]]
		- we exploit the fact that $$\mathcal{L}(\theta^{k+1}) \geq L(\theta^k)$$ the likelihood always improve, never gets worse
	- $Q$ is a weighted average of the complete log-likelihood over all possible latent variables $Z$
		- the weights are the posterior probability
2. M-Step
	- after obtaining $Q$ we can update the model parameters $\theta^{(k+1)}$ by maximizing $Q$ $$\theta^{(k+1)} = \arg \max_{\theta} Q(\theta \mid \theta^{(k)})$$
		- we are implicitly maximizing the complete likelihood

We repeat those step until the estimation and parameters gets stable.
