Let $X$ be sample space and $C= \{ c_{1}, \dots, c_{k} \}$ be the all possible classes, let $f: X \to C$ be the target classification function each instance $x\in X$ is described by a set of $L$ discrete attributes $$x= < a_{1}, \dots, a_{L} >$$ 

The goal is to find the most probable class given the attribute observed $$c_{NB} = \arg \max_{c_{j} \in C} P(c_{j} \mid a_{1}, \dots, a_{L})$$ this estimation is basically a MAP.

Using Bayes theorem we rewrite the posterior$$P(c_{j} \mid a_{1}, \dots, a_{L}) = \frac{P(a_{1}, \dots, a_{L} \mid c_{j}) P(c_{j})}{P(a_{1}, \dots, a_{L})}$$ and because the marginal is equal to all classes we can cancel it out $$c_{NB} = \arg \max_{c_{j} \in C} P(a_{1}, \dots, a_{L} \mid c_{j}) P(c_{j})$$ so basically the posterior is equals to likelihood times prior (MAP analogy).

From the naive assumption we got $$P(a_{1}, \dots, a_{L} \mid c_{j}) = \prod_{l=1}^L P(a_{l}\mid c_{j})$$ ending up with the final formula $$c_{NB} = \arg \max_{c_{j} \in C} P(c_{j}) \prod_{l=1}^L P(a_{l}\mid c_{j})$$
