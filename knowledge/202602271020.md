Self-organizing map neural networks, AKA **Kohonen** maps.

Consists of $N$ neurons arranged in a **low-dimensional grid** (e.g 2D lattice) ![[Pasted image 20260227102824.png]]
- each unit
	- receives the same input $x$
	- has a coordinate on the map e.g $(1,5)$
	- has a weight vector $w$ of the same dimension as the input $x$ $$dim(w)=dim(x)=n$$

We define proximity by **position on this grid**.

![[Pasted image 20260227102604.png]]

The goal of SOM is to learn a **Topology-Preserving map**
1. Neighboring units on the grid should respond to similar input patterns
2. Two data points $x_1$ and $x_2$ close in the input space, are mapped to units that are close on the 2D grid.

The core mechanism is **Competitive Learning**. Neurons compete to represent the input. The winner earns the right to learn. But in SOM, the winner also helps its neighbors learn.

This mitigate the cons of K-means about the visualization of data.
