The spark application's code is uploaded to a "Driver" node (also called "Master node").
- Driver node will build the execution plan graph
- then sparks will divides the work properly to parallelize it over the cluster nodes

Data will be
- distribute and partitioned over worker nodes
![[Pasted image 20250713182637.png]]
- a node will have multiple partitions deployed on them
- a partition is a **block of data**
- a partition is **NOT a node**
