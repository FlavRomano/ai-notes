The Naive Bayes goal is
- from all possible classes
- choose the most probable given the observations

The name "naive" comes because computing the conditional probability $$P(a_{1}, a_{2}, \dots,a_{n} \mid c)$$ is intractable, so we make a powerful assumption:
> Conditional independence between fea given the class

In other words, we go from this $$P(a_{1}, a_{2}, \dots,a_{n} \mid c)$$ to this $$P(a_{1}, a_{2}, \dots,a_{n} \mid c) = P(a_{1}\mid c) P(a_{2}\mid c) \dots P(a_{n}\mid c)$$ much easier then the previous one.
