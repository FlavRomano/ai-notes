$$P(Y_{1}, Y_{2}, Y_{3}) = \underbrace {P(Y_{1})}_{1} \underbrace{P(Y_{2} \mid Y_{1})}_{2} \underbrace{P(Y_{3} \mid Y_{1},Y_{2})}_{4}$$ 

The number of parameters is given by the following rule $$\sum_{i=0}^{N-1} = (k-1)k^i = k^N - 1$$
