In case of *non-linearly separable* TR patterns, we need a function $\Phi$ that 
- maps points in the input space
- to a high-dimensional **feature space**
	- where they can be **linearly separable**

![[Pasted image 20251106170641.png]]

Adding a dimension to the feature space 
- can translate the original non linear problem 
- into a linearly separable problem
- the choice of $\Phi$ is critical

But using high dimensional feature spaces per se (large basis function expansion) [[202511061712|it's not very good]]
- increase the model complexity
- can be computationally unfeasible
- can lead to overfitting

For this reason we introduce the [[202511061723|kernel approach]] to
- manage implicitly the feature space
- we regularize the model

Wrapping things up:
1. Given our training set TR
2. We choose the tradeoff
	- parameter $C$
	- kernel function $k$
3. Compute kernel matrix $M$
4. Solve the dual and find the best Lagrangian multipliers $\alpha_{i}$
5. Compute the bias $b$ knowing the best Lagrangian multipliers and the kernel matrix
6. Given an input pattern $x$
	- we compute the discriminant function $$g(x)= w^T\Phi(x) = \sum_{i=1}^N \alpha_{i} d_{i} k(x,x_{i}) + b$$
	- we **DON'T** compute $w$ (unfeasible)
7. We classify $x$ as the sign of $g(x)$ $$h(x)=sign(g(x))$$
