The core of bagging is
- training the **same type** of model
	- multiple times
	- on **different random subsets of TR**
		- bootstrap resampling
- then 
	- for regression
		- average the outputs
	- for classification
		- majority voting

The effect is
- **variance reduction**
	- each model sees slightly different data
- same bias

The training happens in parallel, we have independent model.

---

Random forest is 
- ensemble of decision trees
	- built on bootstrap samples
	- with random feature selection per split
