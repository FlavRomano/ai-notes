How a neural network can processes temporal sequence?

We use a sliding window approach. 

![[Pasted image 20260227113628.png]]

- We take the current input $l_5$ plus the previous $N$ inputs
	- a buffer
	- e.g $(l_{4}, l_{3}, l_{2}, l_{1})$
- then concatenate them into one big vector and feed it to a standard MLP

This is a finite memory approach in which
- we must know the window dimension in advance
- number of weights depends on the buffer size

| PROS                   | CONS                             |
| ---------------------- | -------------------------------- |
| very simple            | finite shift register            |
| back propagation works | must know window size in advance |
