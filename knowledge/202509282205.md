Validation is a phase of building a model. After models training on $TR$
- Model selection
	- estimates the performance of the different learning models
		- based on generalization error
	- in order to choose the best one (to generalize)
		- includes search the best hyper-parameters
	- returns a model
- Model assessment
	- given a final model estimates its prediction error
		- by generalization error
	- on new test data
		- use a separate data set
	- returns an estimation
