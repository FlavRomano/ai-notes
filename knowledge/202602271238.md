**Unfolding** is a technique used to allow backpropagation on RNN.
> in a RNN we are not in a DAG, we have self loop feedback that creates cycles.

Build a MLP equivalent to the RNN given a specific input sequence. The final network is called *encoding network*.

![[Pasted image 20260227135309.png]]

Layer $T$ of the encoding network is the RNN at time $t=T$.

The fundamental distinction between a standard MLP and an encoding network is that
- in standard MLP each layer has distinct weights
- in an encoding network 
	- every layers shares the exact same weight matrix $W$
