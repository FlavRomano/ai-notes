In transformers a sequence is not processed sequentially, is processed in parallel using attention.

The attention layer weights all previous states according to a learned measure of relevance, providing information about far-away tokens.

That allow the model to look at any part of the pas sequence directly, bypassing the step-by-step memory bottleneck.
