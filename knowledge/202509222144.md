The unbiased learner
- lacks of assumptions about the target function $f$
	- no language bias
	- no search bias
	- 50/50
	- has no rational basis for classifying any unseen data
- has a hypothesis space $H$ large enough to express **every teachable concept**
	- $H$ is the set of all possible subsets of input space $X$
	- power set of $X$

An unbiased learner's version space $VS_{H,TR}$ $$\forall h \text{ consistent with } x_{i}\in TR. \exists h': h' \text{ equals to } h \text{ except } h'(x_{i})\ne h(x_{i})$$ that implies $$h\in VS \implies h'\in VS$$
- classifies each unobserved instance as
	- **positive** by half the hypotheses in the VS
	- **negative** by the other half
	- 50/50
