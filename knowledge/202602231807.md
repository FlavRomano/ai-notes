$$f(x) = \max(0,x) = \begin{cases}
x &x\ge 0 \\
0 &x<0
\end{cases}$$

$$f'(x) = \begin{cases}
1 &\text{for positive net} \\
0 &\text{o/w}
\end{cases}$$

It does not saturate
- the gradient passes through as 1
- solves the vanishing gradient problem
- also
	- cheap
	- induces sparsity (many neurons are 0)
		- several weights are 0
