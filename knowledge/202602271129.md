Transduction is when we map an input sequence to an output sequence or value.

We perform transduction in a domain where
- input is a discrete sequence of vectors over time
	- so they are ordered

![[Pasted image 20260227113137.png]]

There are two main ways to do transduction
1. Sequence classification
	- read the whole sequence
	- then output a class at the end
	- e.g is this sentence positive or negative?
2. Next-step prediction
	- produce an output at every step
	- e.g predicting stock price for tomorrow every single day
