Instead of the gradient descent (iterative approach) we can solve just an equation to minimize the expected loss.
- we need to find the weight vector $w$ 
- where the gradient of $E(w)$ is zero


Imposing the gradient equals to zero we obtain the **normal equation** $$(X^T X)w = X^T y$$ so we can get the hyperparameters $$w = (X^T X)^{-1} X^T y = X^+ y$$  if the $X^T X$ is not singular 
- then we have infinite solution
- so we need to choose which one is more suitable.
