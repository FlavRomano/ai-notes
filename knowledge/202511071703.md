- In **SVM regression** we’re not separating classes 
	- we want to approximate a function 
	- while **tolerating errors**
- Just like the soft margin in classification allows some points to violate the margin
- we need a similar mechanism in regression 
	- to **allow small deviations** from the target values 
	- without penalizing them too hard


We call $\varepsilon$-insensitive loss function $L_{\varepsilon}$
- a loss function
- which **does not** take into account the error
	- on those points 
	- which are closer than a certain tolerance $\varepsilon$ to the hypothesis value

Formally, given an hypothesis $$h(x) = w^T \Phi(x_{p})$$ we define the loss as 
$$
L_{\varepsilon}(d,y) = \begin{cases}
\lvert d- y \rvert - \varepsilon &\text{if }\lvert d-y \rvert \geq\varepsilon \\
0 &\text{o/w}
\end{cases}
$$
We define an $\varepsilon$-insensitive zone around the regression line.  

The insensitive zone is like a tube.

Errors **inside** that tube (smaller than $\varepsilon$) are **ignored**,  
while errors **outside** it are **penalized**:
