The problem of Naive Bayes is related to Maximum Likelihood nature. Is bad when we have few data.

During the conditional probability attribute-class $$P(a_{l}=s \mid c = k)$$ when we classify a new instance, Naive Bayes multiplies every probability. If just one is 0 then the entire probability for that class becomes 0. $$P(a_{l}=s \mid c = k) = 0 \implies P(c=k \mid x) = 0$$ for each instance that contains that value.

That's because ML is data-driven, if some event is not observed in the dataset then it means that is impossible (overfitting).

One way to mitigate this problem is Laplacian Smoothing, instead of starting from zero we can fake to observe same samples. Virtual counts technique.

$$P(a_{l} = s \mid c= k) = \frac{N_{ls}(k) + \alpha}{\sum_{s=1}^{S_{l}} N_{ls}(k) + \alpha}\quad \alpha>0$$ 

The $\alpha$ is **a priori estimate** of the attribute-class probability, because before observing any data we already gave a little bit probability to each possible value. This is exactly like MAP, we are regularizing ML with a prior that encodes out initial beliefs.
