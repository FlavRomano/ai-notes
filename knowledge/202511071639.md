We want to
- guess an unknown non linear function $f$
- given a set of points $x\in \mathbb{R}^N$ 

Given a TR set $$T=(x_{i},d_{i}),\quad i=1\dots N$$SVM can be used to find a good approximation of $f$ such that $$d=f(x) + noise$$ we want to estimate $d$ using LBE of non-linear functions $$\phi_{j}(x), \quad\forall j=0\dots m_{1}$$the predicted value should be $$y=h(x)=w^T \Phi(x)$$
where $$w = (b, w(1), \dots, w(m_{1}))^T$$ $$\Phi(x) = (1, \phi_{1}(x), \dots, \phi_{m_{1}}(x))^T$$
It's crucial to design a [[202511071703|soft margin loss function]], so we are in the case of soft margin SVM because we allow errors.

Even in this case, we define slack variables

![[Pasted image 20251107172214.png]]

as $$\xi_{p}' - \varepsilon \leq d_{p} w ^T \Phi(x_{p}) \leq \varepsilon + \xi_{p},\quad \forall p= 1\dots l$$ so in other words:
- the prediction can go up to $\varepsilon$ above the true value
	- plus some extra slack $\xi_p$​ if it exceeds that limit
- the prediction can go $\varepsilon$ below the true value
	- plus some extra slack $\xi_p'$​ if it exceeds that limit

Of course, even in this kind of SVM we states:
- [[202511071730|primal problem]]
- [[202511071735|dual problem]]

so we can solve the dual problem.

By solving the dual problem we get the optimal Lagrangian multipliers $$\alpha_{i},\alpha_{i}'$$ so we can compute the optimal value for weight vector $$w = \sum_{i = 1}^N (\alpha_{i}- \alpha_{i}') \Phi(x_{i})$$ we can call $\gamma_{i}$ the difference between upward and downward multipliers.

Support vectors correspond to **non-zero** values of $\gamma_{i}$. So we can write down the estimate function $$h(x) = w^T \Phi(x) = \sum_{i=1}^N \gamma_{i} \Phi^T(x_{i}) \Phi(x) = \sum_{i=1}^N \gamma_{i} k(x_{i},x)$$
