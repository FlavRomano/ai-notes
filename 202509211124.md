The optimization problem it's a function where 
$$f_{*}=min\{f(x):x\in \mathbb{R}\}$$
- we need to find the point of the input space $x$ 
	- such that the value of the function is minimum/maximum
	- we are looking at the image of the function $im(f)$
		- if we need the function minimum, then we look at the bottom point of the image 
		- viceversa for the maximum we look for the highest image point
- $f$ is called **objective function**
- the optimization problem in this case is **univariate** and **unconstrained**
![[Pasted image 20250921112659.png]]
- $f_{*}=v(P)$ is the optimal value of the problem
	- we can also think about that in terms of value of level set $$f_{*}=\text{smaller element of }im(f)=\text{smaller } v:L(f,v)\ne \emptyset$$
- we don't really care of the optimal value $y$, we care the most of the **input** $x_{*}$ that gives me the optimal value $$(P) \quad x_{*} \in argmin \{f(x): x \in \mathbb{R}\}$$ $$x_{*} : f_{*}=f(x_{*})\leq f(x).\forall x\in \mathbb{R} \text{ optimal solution if exists}$$
![[Pasted image 20250921113304.png]]

Maybe more than one optimal solution. $$X_{*}=\text{set of optimal solutions}$$
- we want any one of them
- all optimal solutions are equivalent in *the eyes of $f$*
---
We can consider equivalent problem by reformulating $(P)$
$$min\{f(x):x\in \mathbb{R}\} = -max\{-f(x) : x\in \mathbb{R}\}$$ $$argmin\{f(x):x\in \mathbb{R}\} = argmax\{-f(x):x\in \mathbb{R}\} $$
The optimal solution space $X_{*}$ does not change

---
We don't really care about constant inside objective function $$min\{f(x) + c : x \in \mathbb{R}\} = c  + min\{f(x) :x\in \mathbb{R}\}$$ The optimal value of $f_*$ will be shifted vertically by $c$.
Analogously with constants that scale $f(x)$.
