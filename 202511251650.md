Deep learning is 
- a general framework
- including different models
	- [[deep neural networks]] (MLP with many layers)
	- [[convolutional neural networks]]
	- [[recurrent neural networks]]

Common aspects of this framework are
- [[202511251715|no flattening]]
- multiple layers of nonlinear processing units
- feature learning and [[202511251659|hierarchical feature extraction]] (vs. features engineering)
	- different levels of abstraction
		- [[202511251749|inductive bias]]
			- [[202511281141|empirical results]]
		- layers forming a hierarchy
		- from low-level to high level features
- hierarchical [[distributed representation]] of the input data

> Less units and less weights $\implies$ good generalization with less examples
