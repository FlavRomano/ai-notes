> There are functions that 
> - a deep network represents in a **compact** way (polynomial, efficient)
> - a shallow network represents in a **huge** way (exponential, inefficient)

No-flattening means that
- we cannot always flatten a deep network into a shallow one
- maintaining the same efficiency

From the universal approximation tells us that
- one layer with a lot of units is sufficient to approximate every function
- we don't know the number of units

But for certain functions one layer is not enough.

For *compositional function* (that can be built by combining subparts)
- the deep models are more efficient
	- exploits compositionality of internal representations
		-  *simple concepts in one layer become **primitive** for the next layer*
	- by reusing internal concepts
