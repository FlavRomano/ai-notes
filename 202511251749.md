> *Nature has a hierarchical structure itself*

Inductive bias of deep models 
- function we want to learn
	- are composition of several, simpler, functions
- it's a well known bias that applies in many context
	- e.g: Pixel → edges → shapes → object's part → objects → picture

----

We are making a generic but bold assumption
- if task is **not** hierarchical
- if the function has **not** a compositional structure
- if the phenomena is random or linear

then deep model **HAS NO ADVANTAGES**:
- more computationally heavy
- more difficult training
- can overfit rapidly (with few data)
