The **VC-dimension** (Vapnik–Chervonenkis dimension) 
- is a measure of the **complexity** of a hypothesis class $H$
	- how expressive or complex a set of models is.
	- the flexibility to fit data.

Formally
> The VC-dimension of $H$, is the **largest number of points that can be _shattered_** by $H$

---

A set of points is said to be **shattered** by $H$ if, 
- for **every possible labeling** of those points 
	- (assigning each one a 0 or 1)
- there exists a hypothesis $h \in H$ that correctly classifies them.

e.g: If you pick $n$ points, 
- and for all $2^n$ possible labelings
	- you can find a classifier in $H$ that matches it
- then $H$ shatters those points.
