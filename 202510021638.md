## 1
with much higher input dimension $n$ 
- we need to cover more distance to capture a fraction of the data. 
- See the slides. 
- So the similarity in the distance between the $n$ changes a lot. 

Exponential effect according to $n$. The only way to reduce this problem with high $n$ is to reduce the $k$, but dropping the $k$ we go in overfitting surely. So there isn't a solution. We cannot just extend the radius, because the $n$ space is so empty that we cannot fix a radius (it will be very big)

## 2

So we will need to exponentially increase the number of our data, to balance the emptiness.
