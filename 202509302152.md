Given a set of $l$ training examples $$<x_{p}, y_{p}>, p=1..l$$ we want to find $h_{w}(x)$ in the form $w_{1}x+ w_{0}$, so find the best $w$ that minimizes the expected loss on the training data.

For the loss 
- we use the square errors so
- find $w$ to minimize the residual sum of squares $$Loss(h_{w}) = E(w)= \sum_{p=1}^l (y_{p} - h_{w}(x_{p}))^2 = \sum_{p=1}^l (y_{p} - (w_{1}x_{p} + w_{0}))^2$$ ![[Pasted image 20250930220333.png]]

Assuming $x$ and $w$ as column vector $$w^T x + w_{0} = w_{0} + w_{1}x_{1} + w_{2}x_{2} + \dots + w_{n}x_{n} = w_{0} + \sum_{i=1}^n w_{i}x_{i}$$ so $w_{0}$ is called bias because it's the only term independent from the input $x$.

Including a constant $x_{0}=1$
- we don't change the inner product $$x^T = (1,x_{1},x_{2},\dots,x_{n})$$ $$w^T = (w_{0},w_{1}, w_{2}\dots,w_{n})$$
- we can rewrite the equation to $$w^T x = x^T w$$

So the linear model can be written 
- as a function 
- that for each $x_{p}$ compute $$h(x_{p}) = x_{p}^T w = \sum_{i=0} ^n x_{p,i}w_{i}$$
