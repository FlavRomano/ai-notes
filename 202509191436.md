- Trained examples $<in,out> = <x,d>$  
- for an unknown function $f$
	- we now only some point of the function by the examples
- target value 
	- desiderate value
	- $d$, $t$ or $y$
	- is given by the teacher according to $f(x)$ to label the data
--- 
A good approximation of $f$ is called **hypothesis** $h$
- $h$ can be used for predict on unseen data $x'$
	- $h(x,w)$ where $w$ are abstract parameter
- $H$ is the hypotheses space
	- space of possible different models
- if it's good with unseen data 
	- then it generalize good 
	- then it's a good approximation
---
Given examples we want to find a good $h$

---
If target value 
- categorical
	- then we are approximate discrete values
	- the problem is classification
- numerical
	- then we are getting real continuous output value
	- the problem is regression
