Rosenblatt propose a learning algorithm **different from LMS**
- only classification, no regression
- we are going to minimize the number of misclassification
	- no explicit loss
	- different approach respect to LMS
- if the answer is correct, we don't change the weights

---
Geom. view
- Remember that $w$ is orthogonal to the separation boundary.
- $p_1$ (and $p_{2}$ also) is misclassified
- with $w_{new}$ the new decision boundary appears
	- $p_1$ (and $p_{2}$ also) is now correctly classified
- it's a sort of implementation of Hebbian rule
	- $w$ moves towards $x$
