Given an hypotheses space $H$, one hypothesis $h$ in $H$
- is a function similar to the target function $f$
- is written in some language

The **language of the hypothesis space** 
- is the mathematical form or structure of the functions 
- that the learning algorithm is allowed to consider 
	- when searching for the best approximation of $f$.

If we fix a hypothesis space $H$, 
- then **all hypotheses $h∈H$ share the same language** 
	- same form of representation
- but they differ in their **parameters**.

---
The language it's defined by the model family or the function class we allow.

- If we use **linear regression**
	- the language is _linear functions_ of the inputs.
- If we use a **decision tree**
	- the language is _tree-based decision rules_
- If we use a **neural network** 
	- the language is _compositions of nonlinear functions with weights and activations_.
